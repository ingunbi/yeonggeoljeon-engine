# 41 방문한 상점의 판매 물품 기록

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 우선순위: P3
- 개발 단계: M4
- 선행조건: F3 관측 기록 저장, F4 상점 관측 사건, F6 정보 색인
- 기준일: 2026-11-09

## 목적과 현재 구현

어느 도시에서 물품을 팔았는지 기억하지 않아도 찾을 수 있게 한다. 현재 [OriginalCampaignView.swift](../../../Sources/YeonggeoljeonEngine/OriginalCampaignView.swift)의 `shopRows`는 방문 중인 상점 정보만 표시하고, [OriginalShop.swift](../../../Sources/YeonggeoljeonEngine/OriginalShop.swift)의 `stock`은 장과 도시의 재고를 조회한다.

## 사용 흐름과 화면

1. 상점의 판매 물품을 실제로 확인하면 관측 기록을 남긴다.
2. 물품 기록 화면에서 이름·효과·도시로 검색한다.
3. 결과에 마지막으로 본 가격과 장·도시·확인 시점을 표시한다.
4. 같은 도시의 재고가 바뀌면 재방문 후 새 관측으로 갱신한다.
5. 현재 방문 가능한 도시만 세계지도 안내로 연결한다.

## 구현 범위와 데이터

- 제안 타입 `ObservedShopStock`은 회차, 장, 도시·상점 식별값, 관측 순번, 물품 ID와 관측 당시 가격을 가진다.
- 원본 카탈로그 전체를 열어 미래 도시의 판매품을 자동 채우지 않는다.
- 기록 발생점은 판매 목록을 실제로 표시한 경계다. 입장하지 않은 도시나 열지 않은 상점은 기록하지 않는다.
- 가격은 현재 수식으로 과거 값을 재계산하지 않고 확인 당시 값을 보존한다.
- 결과에는 ‘마지막 확인 정보’임을 표시하며 현재 재고나 가격을 보장하지 않는다.
- 33번 장바구니는 현재 거래를, 이 문서는 과거 관측 정보 탐색을 담당한다.

## 저장과 호환

기록은 F3의 회차 확장 데이터로 실제 게임 저장과 함께 원자적으로 기록한다. 이전 저장에는 관측 없음으로 시작한다. 과거 저장을 불러오면 미래 시점 관측이 역으로 섞이지 않게 한다.

## 예외와 취소

자료 식별값이 달라지면 과거 관측임을 표시하고 현재 상점으로 직접 연결하지 않는다. 기록 쓰기 실패를 구매 성공으로 오인하지 않는다. 관측 자체는 돈·소지품·난수를 바꾸지 않는다.

## 완료 기준

- [ ] 실제로 본 판매 목록만 기록된다.
- [ ] 가격과 재고가 바뀐 뒤 이전 관측을 현재 정보처럼 표시하지 않는다.
- [ ] 재방문 시 같은 상점의 최신 관측으로 갱신한다.
- [ ] 과거 저장 복원에서 이후 도시·판매품 정보가 남지 않는다.
- [ ] 검색과 도시 연결은 현재 이동 가능한 범위만 사용한다.

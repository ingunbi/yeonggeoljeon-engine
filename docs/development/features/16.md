# 16. 부대 목록 정렬과 필터

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P1 · 단계: M1
- 선행조건: 기존 부대 목록과 읽기 전용 조건 조회. 다른 미리보기 기능의 완료와 독립적이다.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [OriginalBattleScreen.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleScreen.swift)의 `OriginalBattleRoster.rows`는 소속과 퇴각 상태로 고정 순서를 만든다.
- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `drawSidebar`는 아군/적군 탭과 병력 목록을 그린다.
- 같은 파일의 `readyUnits`·`selectNextUnit`는 행동 가능한 아군을 slot 순서로 순환한다.
- 추가 기능은 화면 목록을 사용자 기준으로 좁히고 정렬하며 실제 부대 저장 순서는 바꾸지 않는다.

## 목적과 화면 흐름

1. 목록 상단에서 미행동·낮은 병력·혼란·회복 책략 가능 필터를 고른다.
2. 이름·레벨·현재 병력·병력 비율 기준으로 정렬 방향을 바꾼다.
3. 표시된 장수를 선택하면 위치를 보여주고, 행동 가능하면 기존 선택 절차로 이어진다.
4. 행동을 마친 장수나 적은 정보 조회와 카메라 이동만 허용한다.
5. 결과가 없으면 적용 중인 조건과 필터 해제 버튼을 제공한다.

## 구현 범위와 진입점

- 신규 타입 제안 `RosterViewOptions`는 side, 필터 집합, 정렬 키·방향을 가진다.
- `OriginalBattleRoster.rows`의 결과를 입력으로 하는 표시 전용 projection을 둔다.
- 행 식별은 정렬 인덱스가 아니라 runtime slot과 person ID를 사용한다.
- 미행동은 단순 색상 대신 `readyUnits`의 수동 행동 자격과 같은 조건을 공유한다.
- 낮은 병력은 예를 들어 현재/최대 50% 이하로 정의하고 화면에 기준을 명시한다.
- ‘회복 책략 가능’은 현재 병과·레벨·MP·행동 상태 조건을 뜻하며 실제 회복 대상 존재와는 구분한다.
- 적 목록은 기존 공개 여부를 유지하며 숨겨진 적이 개수·정렬 결과로 노출되지 않게 한다.
- 정렬 동률은 원래 slot 순서로 안정적으로 처리한다.
- 선택된 장수가 필터 밖으로 나가면 잘못된 다른 행을 선택하지 않고 선택 상태를 정리한다.
- Tab 순환은 기존 행동 순서를 유지하며, 화면 정렬에 따르는 변경은 별도 요구 없이는 추가하지 않는다.

## 저장과 예외

- 정렬·필터는 사용자 UI 설정으로 저장하고 전투 상태·부대 배열에는 저장하지 않는다.
- 이전 설정에 필드가 없거나 키가 알 수 없으면 기본 목록으로 복원한다.
- 저장된 필터가 새 전장에서 빈 결과를 만들면 활성 필터를 명확히 보여준다.
- 지도 변경·퇴각·상태 변화·레벨업 후 목록을 다시 만들고 스크롤 위치를 유효 범위로 제한한다.
- UI 정렬은 출전 슬롯·이벤트 식별·AI 행동 순서·RNG를 변경하지 않는다.
- 원작 모양 화면을 지원할 때도 현대식 필터 조작부가 원래 입력 영역을 침범하지 않게 한다.

## 완료 기준

- [ ] 각 필터와 복합 필터가 합성 부대의 실제 상태를 반영한다.
- [ ] 병력 절대값과 비율 정렬이 구분되고 동률 순서가 안정적이다.
- [ ] 정렬 후 클릭이 해당 장수를 가리키며 퇴각·필터 이탈 때 다른 장수로 바뀌지 않는다.
- [ ] 화면 정렬 전후 실제 슬롯·행동 순서·RNG·저장 진행 상태가 동일하다.
- [ ] 숨겨진 적이 행·숫자·빈 결과 안내로 노출되지 않는다.
- [ ] 실제 창에서 목록 스크롤·필터 해제·Tab 기존 동작을 확인한다.

## 작업 순서

1. 표시 projection과 필터 정의를 기존 판정 기준에 맞춘다.
2. 안정 정렬·선택 식별·빈 결과 상태를 구현한다.
3. 사이드바와 설정 복원, 카메라 이동을 연결한다.
4. 합성 목록과 실제 창에서 정렬·선택·상태 변경 흐름을 검증한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

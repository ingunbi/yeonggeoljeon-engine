# 26. 상태 이상 설명과 해제 안내

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P1 · 단계: M1
- 선행조건: F2 상태·행동 제한·회복 조건 조회. 다른 추천 기능의 완료와 독립적이다.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `drawUnitCard`는 혼란·매복·퇴각 표식을 표시한다.
- [StrategyGuideDetails.swift](../../../Sources/YeonggeoljeonEngine/StrategyGuideDetails.swift)의 `describe`에는 혼란의 행동·반격 제한 설명이 있다.
- [OriginalCombat.swift](../../../Sources/YeonggeoljeonEngine/OriginalCombat.swift)의 `recoverCondition2`는 방어 관련 원본 수치·사기를 바탕으로 난수 판정한다.
- 추가 기능은 현재 장수의 표식에서 구체적인 제한과 해제 방법을 바로 확인하게 한다.

## 목적과 화면 흐름

1. 지도 또는 장수 카드의 상태 표식을 누른다.
2. 현재 상태, 제한되는 행동, 회복 가능한 방법과 적용 조건을 읽는다.
3. 회복이 확률 판정이면 확률·판정 시점과 불확실성을 구분해 본다.
4. 회복 수단 검색 25가 준비된 경우 해당 장수의 검색으로 이동한다.
5. 초기 구현에서는 25 없이도 상태 설명과 일반 회복 안내를 완결되게 제공한다.

## 구현 범위와 진입점

- 신규 타입 제안 `UnitConditionDetail`은 상태 종류, 제한 목록, 회복 경로, 확률 설명과 근거를 가진다.
- 상태는 runtime의 `status`, `scriptFlags`, 사기를 읽고 알려진 의미만 표현한다.
- 혼란·매복·퇴각·행동 완료를 모두 같은 상태 이상으로 취급하지 않는다.
- 행동 제한은 실제 명령 자격과 반격 규칙에서 읽으며 UI 전용 금지 목록을 만들지 않는다.
- 자연 회복 판정 시점은 [OriginalTurns.swift](../../../Sources/YeonggeoljeonEngine/OriginalTurns.swift)의 실제 호출 흐름을 따른다.
- 사기 회복 도중의 상태 회복은 `heal`·`setMorale`의 처리 순서를 따른다.
- 확률을 숫자로 보여주면 `recoverCondition2`의 정수 임계값과 난수 범위를 사용하고 0~100% 표시를 명확히 한다.
- 현재 RNG의 다음 값을 조회해 ‘이번 턴 해제’라고 예고하지 않는다.
- 임의의 남은 턴 수는 만들지 않으며, 정확한 시점을 확인할 수 없으면 조건 설명만 제공한다.
- 적 상태는 현재 공개된 표식과 정보만 설명하고 매복 적의 존재를 목록에 추가하지 않는다.

## 저장과 예외

- 상태 설명은 현재 상태의 파생 정보이므로 저장하지 않는다.
- 이전 저장의 실제 상태 필드를 그대로 읽으며 설명용 상태 플래그를 추가하지 않는다.
- 상태 변경·퇴각·장수 교체 시 열린 설명을 갱신하거나 닫는다.
- 알려지지 않은 상태 조합은 일반적인 표시로 제한하고 임의의 해제 규칙을 안내하지 않는다.
- 조회는 실제 상태·사기·난수·행동 권한을 변경하지 않는다.
- 회복 안내를 읽는 것과 실제 도구/책략 사용을 분리하고 기존 확인 절차를 유지한다.

## 완료 기준

- [ ] 혼란의 이동·행동·반격 제한이 실제 명령 자격과 일치한다.
- [ ] 행동 완료·매복·퇴각을 혼란의 회복 대상으로 잘못 안내하지 않는다.
- [ ] 회복 확률·시점이 실제 정수 규칙에 맞고 가상의 남은 턴을 표시하지 않는다.
- [ ] 사기 회복·자연 회복·회복 불가 조건이 구분된다.
- [ ] 설명 조회 뒤 상태·RNG가 동일하며 비공개 적의 정보가 노출되지 않는다.
- [ ] 실제 창에서 작은 상태 표식의 선택·설명 읽기·복귀를 확인한다.

## 작업 순서

1. 현재 표시 중인 상태와 실제 제한·해제 생산 지점을 대응시킨다.
2. F2의 상태 상세 결과와 확률 설명을 정의한다.
3. 지도·카드 표식에서 읽기 상세를 열고 선택적으로 25에 연결한다.
4. 합성 상태 조합과 실제 창의 표식 접근성을 검증한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

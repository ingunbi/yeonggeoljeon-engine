# 11 전직을 미리 보는 성장 계획

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 우선순위: P2
- 개발 단계: M2
- 선행조건: F1 읽기 전용 투영, F2 전직 조건 조회
- 기준일: 2026-11-09

## 목적과 현재 구현

도구를 얻거나 전직 레벨에 도달하기 전에도 육성 방향을 비교한다. 현재 [PromotionPreview.swift](../../../Sources/YeonggeoljeonEngine/PromotionPreview.swift)의 `build`는 도구 보유와 병과·레벨 조건을 검사한다. 이 실행용 미리보기의 검사를 약화하지 않고 계획용 조회를 분리한다.

## 사용 흐름과 화면

1. 장수 정보에서 성장 계획을 연다.
2. 현재 병과에서 원본 도구 규칙으로 연결되는 전직·병종 변경 후보를 선택한다.
3. 필요 도구·레벨·현재 부족한 조건과 능력치, 지형 이동, 공격 범위, 책략 변화를 나란히 본다.
4. 비교 기준은 기본적으로 현재 레벨·장비·지정 사기이며, 실행 가능 여부를 별도 배지로 표시한다.
5. 닫기 또는 뒤로는 장수 정보의 기존 선택으로 돌아온다.

## 구현 범위와 데이터

- 제안 타입 `PromotionPlan`은 현재 인물 값, 후보 도구 ID, 목표 병과, 조건 판정, 비교 기준을 가진다.
- [OriginalItems.swift](../../../Sources/YeonggeoljeonEngine/OriginalItems.swift)의 `OriginalItemUse.of`, `classRefusal`에서 확인된 분기만 후보로 쓴다.
- 능력치 투영은 기존 `PromotionPreview.Facts` 계산을 공유하도록 분리하되 실제 전직은 기존 도구 실행에 남긴다.
- 미보유 도구를 비교할 때 가상의 도구를 실제 소지품에 넣거나 소비하지 않는다.
- 실제 전직 예측과 같게 보유 도구의 소비 효과를 반영할 때는 비교 기준에 명시한다.
- 조회 화면에는 즉시 전직 버튼을 두지 않는다. 실행하려면 기존 도구 사용 경로로 돌아간다.

## 저장과 호환

조회 중 후보와 스크롤은 화면 상태이며 캠페인 저장에 필수로 넣지 않는다. 장수의 능력치·병과·소지품은 변경하지 않는다. 이전 저장에도 현재 인물과 규칙 자료로 계산할 수 있어 별도 마이그레이션이 필요하지 않다.

## 예외와 취소

자료가 불완전한 병과는 수치를 0으로 채우지 않고 조회 불가를 표시한다. 주인공 제한·지형 제한 등 실제 실행 조건과 계획 비교 가능 여부를 구분한다. 전투 중에는 해당 장수의 현재 사기를 사용하고 필드 비교 기준을 명시한다.

## 완료 기준

- [ ] 도구가 없거나 레벨이 낮아도 조건과 비교를 읽을 수 있다.
- [ ] 실제 전직 가능 상태의 비교 결과는 기존 실행 미리보기와 같다.
- [ ] 도구 소비, 병력 회복, MP 회복이 조회 때문에 발생하지 않는다.
- [ ] 병과별 책략 습득·상실과 지형 통행 변화가 정확히 표시된다.
- [ ] 취소 전후 인물·난수·행동 상태가 동일하다.

## 작업 순서

계산과 실행 자격 검사 분리 → 후보·조건 투영 → 장수 정보 진입 → 상세표 재사용 → 실행 미리보기와 교차 검증 순서로 진행한다.

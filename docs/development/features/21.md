## 목적과 현재 구현

창 전체를 키우지 않고 전장의 배치를 넓게 보거나 부대 주변을 확대한다. 현재 [OriginalBattleScreen.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleScreen.swift)의 `OriginalBattleCamera`는 고정된 행·열 수로 이동한다. [CanvasTheme.swift](../../../Sources/YeonggeoljeonEngine/CanvasTheme.swift)의 `CanvasGeometry`는 전체 캔버스 배율이다.

## 사용 흐름과 화면

1. 지도 영역의 보기 버튼에서 기본·확대·전체 전장을 고른다.
2. 확대는 현재 선택 부대 또는 커서 지점을 중심으로 한다.
3. 전체 전장에서는 부대와 범위를 보고 위치를 선택한다.
4. 위치를 선택하면 직전 전술 배율로 돌아가 해당 칸을 중앙에 둔다.
5. 전체 전장 화면에서 공격·이동을 바로 확정하지 않는다.

## 구현 범위와 데이터

- 제안 타입 `BattleMapViewport`는 지도 영역, 셀 크기, 중심, 배율 모드, 직전 전술 배율을 가진다.
- 그리기와 입력의 좌표 변환을 한 쌍으로 만들고 부대·경로·범위·커서·미니맵 시야에 공통 적용한다.
- 초판은 기본·확대·전체 세 모드로 제한한다. 아트는 nearest-neighbor로 표시하고 가능한 범위에서 정수 디바이스 픽셀을 사용한다.
- 화면 바깥 클릭과 사이드바 클릭은 지도 칸으로 변환하지 않는다.
- 원작 화면 틀은 기존 카메라를 유지하고 현대 화면에서만 지도 배율을 제공한다.
- 선택 부대와 이동 취소 원점은 배율 변경과 무관한 지도 좌표로 보존한다.

## 저장과 호환

기본 선호 배율은 사용자 설정이다. 현재 중심과 전체 전장 전환 상태는 UI 상태로 두며 기존 저장에 필수 필드를 추가하지 않는다. 중단 복원 시 선택 부대를 보여주는 기본 배율로 안전하게 복구할 수 있다.

## 예외와 취소

지도보다 화면이 클 때 중앙 정렬과 경계 제한을 적용한다. 대사·일기토·확대 교전 중에는 지도 배율 입력을 잠근다. 창 크기나 디스플레이 배율이 바뀌면 중심을 보존하며 변환을 다시 계산한다.

## 완료 기준

- [ ] 모든 보기 모드에서 같은 부대의 그리기·선택 위치가 일치한다.
- [ ] 네 지도 모서리와 가장자리에서 범위 밖 칸이 선택되지 않는다.
- [ ] 전체 전장 위치 선택은 이동·공격·턴 소비를 만들지 않는다.
- [ ] 범위·경로·미니맵 시야가 현재 배율과 정확히 맞는다.
- [ ] 창 크기·Retina 배율 변경 후 선택과 화면 중심을 유지한다.

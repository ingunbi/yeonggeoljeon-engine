# 18. 이동 중 지형 정보 표시

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P1 · 단계: M1
- 선행조건: F1의 경로 스냅샷, F2의 이동·지형 규칙. 01·02·27과 상호 완료 의존은 없다.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `showTerrain`은 빈 칸 클릭 시 지형명·방어율·회복 여부를 보여준다.
- 같은 파일의 `drawRoute`는 경로 선과 도착점을 그리며 이동 소모량은 표시하지 않는다.
- [OriginalBattle.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattle.swift)의 `movementBudget`는 현재 장비 이동 보너스를 반영한다.
- [OriginalAI.swift](../../../Sources/YeonggeoljeonEngine/OriginalAI.swift)의 `cost`, `distanceField`, `route`가 실제 이동 규칙을 소유한다.

## 목적과 화면 흐름

1. 이동할 아군을 선택한 뒤 지도 칸에 커서를 둔다.
2. 지형명, 방어 효과, 해당 병과의 한 칸 진입 비용을 읽는다.
3. 도달 가능하면 선택된 실제 경로의 총소모와 남은 이동력을 함께 본다.
4. 도달 불가면 총소모를 정상 값처럼 보이지 않고 27의 이유 안내로 연결한다.
5. 기존 빈 칸 클릭 팝업도 유지하며 정보 표현을 공통화한다.

## 구현 범위와 진입점

- 신규 타입 제안 `TerrainMoveDetail`은 terrain ID, 이름, 방어율, 회복 표식, 진입 비용, 경로 비용·잔여값을 가진다.
- `drawField`의 `hoveredCell`과 `.moving(slot)`에서 읽고 하단 안내나 작은 카드에 표시한다.
- 한 칸 비용은 현재 병과의 `OriginalMovementProfile.cost`를 사용한다.
- 전체 비용은 실제 `route`가 선택한 순서에서 진입 비용을 합산하고 시작 칸을 중복 계산하지 않는다.
- 현재 장비가 반영된 `movementBudget`에서 경로 비용을 빼며 남은 값의 의미를 ‘이동 확정 전 예산’으로 명확히 한다.
- source distance field와 경로 추적 결과가 다르면 임의의 최단경로 알고리즘으로 바꾸지 않고 불일치를 조사한다.
- 방어율은 해당 지형의 방어 효과이며 모든 책략 피해에 같은 감소율이 적용되는 것으로 설명하지 않는다.
- 회복 표식은 해당 지형이 회복 지형임을 뜻하며, 정확한 다음 턴 회복량이 확인되지 않으면 숫자를 만들지 않는다.
- 지도 밖, 이름 없는 지형, 비용 255는 각각 범위 밖·자료 없음·통행 불가로 구분한다.
- 원본 이동 수식을 UI에 복사하지 않고 비용·경로 결과를 F2에서 받는다.

## 저장과 예외

- 커서 정보와 경로 비용은 저장하지 않고 상태 변경·재개 시 재계산한다.
- 선택 병과·장비·지도 지형·점유 상태가 바뀌면 캐시를 무효화한다.
- 이미 이동을 확정한 상태에서는 추가 이동 여유로 오해할 숫자를 표시하지 않는다.
- 숨겨진 적의 영향으로 경로가 제한된 경우 위치·이름·방해 방향을 공개하지 않는다.
- 조회는 실제 위치·이동 원점·행동 플래그·RNG·기록을 변경하지 않는다.
- 이전 저장은 추가 데이터 없이 이용할 수 있으며 원작 파일은 수정하지 않는다.

## 완료 기준

- [ ] 같은 지형에서도 병과별 비용과 통행 불가가 올바르게 달라진다.
- [ ] 장비 이동 보너스·시작 칸 제외·우회 경로의 총소모가 실제 경로와 일치한다.
- [ ] 남은 이동력을 추가 행동 권한처럼 표시하지 않으며 이동 확정 후 안내가 전환된다.
- [ ] 지형 방어율과 책략의 개별 환경 효과를 혼동하지 않는다.
- [ ] 반복 조회가 상태·RNG를 보존하고 숨겨진 적의 정보가 새로 나타나지 않는다.
- [ ] 실제 창의 경로·카드·커서 겹침과 지도 가장자리 배치를 확인한다.

## 작업 순서

1. 기존 비용·경로·지형 표시의 공통 조회 결과를 정의한다.
2. 병과·장비별 경로 비용과 잔여 예산을 연결한다.
3. 이동 커서 카드와 기존 지형 팝업을 통합한다.
4. 합성 이동 경계와 실제 창에서 정보 위치·상태 변경을 검증한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

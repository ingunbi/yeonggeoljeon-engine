# 04. 범위 책략을 쓰기 좋은 위치 추천

- 상태: 부분 구현 · 안정화 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P2 · 단계: M3
- 선행조건: [01 이동 전 예측](01.md), [09 사용 불가 이유](09.md), F1/F2의 범위 효과·조건 조회.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [StrategyGuideDetails.swift](../../../Sources/YeonggeoljeonEngine/StrategyGuideDetails.swift)의 `describe`는 사거리와 적용 범위 모양을 안내한다.
- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `legalStrategyTargets`는 선택 가능한 대상을 검사한다.
- [OriginalStrategyOperation.swift](../../../Sources/YeonggeoljeonEngine/OriginalStrategyOperation.swift)는 중심·주변·시전자 중심 효과의 실제 실행 순서를 소유한다.
- 추가 기능은 합법적인 이동 위치와 선택 대상 조합을 비교해 좋은 후보를 정렬한다.

## 목적과 화면 흐름

1. 아군의 범위 책략을 고르고 ‘위치 추천’을 연다.
2. 현재 위치 또는 이번 턴 도달 가능한 위치 기준으로 후보를 본다.
3. 공격은 대상 수·성공 시 피해 범위·MP, 회복은 실제 병력/사기 회복량을 비교한다.
4. 후보를 선택하면 이동 경로와 적용 대상을 강조한다.
5. 사용자는 기존 이동·대상 확인 절차에서 실행을 확정한다.

## 구현 범위와 진입점

- 신규 타입 제안 `AreaStrategyCandidate`는 도착 위치, 중심 대상, 대상별 효과, 비용과 비교 지표를 가진다.
- 이동 가능 위치는 01의 조회를 쓰며, 이동을 마친 부대는 현재 위치만 계산한다.
- 중심 대상이 필요한 책략과 시전자 중심 전체 적용을 별도 후보 형태로 표현한다.
- 범위 모양만으로 적중을 세지 않고 실제 지형·진영·상태·공개 여부 제한을 F2로 검사한다.
- 같은 대상이 여러 위치에서 후보에 등장해도 한 후보의 합계에서는 중복 집계하지 않는다.
- 회복량은 상한을 적용한 실제 증가량으로 계산하며 병력과 사기를 서로 다른 단위로 표시한다.
- 상태 해제는 확정 회복량에 더하지 않고 확률/조건 항목으로 분리한다.
- 총피해는 성공 시 범위와 성공 확률을 나누며, 평균값을 쓴다면 평균임을 명시한다.
- 비교 동률은 대상 수·MP·이동 비용·좌표 등의 고정 순서로 결정하여 UI가 흔들리지 않게 한다.
- 중심 퇴각 뒤 스크립트가 주변을 바꿀 수 있는 경우 후속 합계는 현재 배치 기준이라는 한계를 붙인다.

## 저장과 예외

- 후보 목록과 선택 강조는 임시 정보이며 세이브에 넣지 않는다.
- 예측은 실행기의 `advance`를 실제 세션에 호출하지 않고 RNG·MP·행동을 보존한다.
- 지도·날씨·부대·물품 상태가 바뀌면 후보를 재계산하고 실행 전 최신 조건을 확인한다.
- 보이지 않는 적은 대상 수와 합계에도 넣지 않는다.
- 유효 후보가 없으면 이유와 현재 위치 사용 가능 여부를 보여준다.
- 공통 예측이 지원하지 않는 효과는 추천에서 제외하고 해당 한계를 표시한다.

## 완료 기준

- [ ] 중심 십자 범위와 시전자 중심 회복에서 실제 유효 대상 집합과 후보가 일치한다.
- [ ] 지형 제한·날씨·이동 후 점유가 반영되고 불가능한 후보가 추천되지 않는다.
- [ ] 회복 상한으로 버려지는 양을 회복 점수에 포함하지 않는다.
- [ ] 성공 확률·혼란 해제·스크립트 경계의 불확실성이 합계에 명시된다.
- [ ] 후보 생성·정렬·취소를 반복해도 실제 상태·RNG·기록이 동일하다.
- [ ] 실제 창에서 후보 선택만으로 행동하지 않고 기존 실행 확인을 거친다.

## 작업 순서

1. 범위 효과의 공통 조회와 합산 단위를 정의한다.
2. 현재 위치 후보부터 합법 대상·회복 상한 검증을 만든다.
3. 01의 이동 후보와 정렬·강조 UI를 연결한다.
4. 합성 검증과 실제 창에서 추천→확정 흐름을 별도 확인한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

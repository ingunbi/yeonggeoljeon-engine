# 27. 이동할 수 없는 이유 표시

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P1 · 단계: M1
- 선행조건: F1 경로 조회, F2 이동 규칙 진단. 01·02·18과 상호 완료 의존은 없다.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `clickField`는 도달 불가 시 일반 `outOfMoveRange` 문구를 사용한다.
- [OriginalBattle.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattle.swift)의 `reachable`은 비용과 도착 칸 점유를 반영한다.
- [OriginalAI.swift](../../../Sources/YeonggeoljeonEngine/OriginalAI.swift)의 `distanceField`는 지형 비용·적 점유·이동 방해를 적용한다.
- 추가 기능은 확인 가능한 불가 사유를 구분하고 합법적인 우회 경로가 있으면 안내한다.

## 목적과 화면 흐름

1. 이동 선택 중 도달 불가 칸을 가리키거나 클릭한다.
2. 이동력 부족, 병과 통행 불가, 공개된 부대 점유, 공개된 적 이동 방해를 구분해 읽는다.
3. 합법적인 대체 경로가 있으면 실제 이동 가능한 경로를 강조한다.
4. 여러 이유가 겹치면 주요 사유와 상세 사유를 분리한다.
5. 정보를 확인할 수 없는 제한은 일반 안내로 유지한다.

## 구현 범위와 진입점

- 신규 타입 제안 `MovementAvailability`는 목적지, 가능 여부, 공개 가능한 이유 코드, 확인된 경로와 비용을 가진다.
- F2가 실제 이동 커널과 같은 조건 생산 지점에서 진단 결과를 반환하도록 설계한다.
- 단순히 거리 차이나 색상만 보고 원인을 역추정하지 않는다.
- 현재 병과 지형 비용 255, 실제 이동 예산, 도착 점유를 서로 다른 이유로 표현한다.
- 아군 통과 가능과 도착 불가는 구분하며, 적 인접 칸에서 탐색이 멈추는 실제 규칙을 설명한다.
- 시작 칸에서 적 방해를 벗어나는 예외와 `scriptFlags`의 이동 방해 예외도 실제 커널을 따른다.
- 경로를 다른 알고리즘으로 대체하지 않고 기존 `route`의 선택 및 방향 순서를 보존한다.
- 공개 정보만으로 원인을 증명할 수 없으면 숨겨진 점유·방해의 이름·방향·좌표를 표시하지 않는다.
- 검사를 위해 숨겨진 적을 제거한 계산을 실제 이동 결과로 채택하지 않는다.
- 지형/점유 변경에 따라 진단을 재계산하고 이전 사유를 남기지 않는다.

## 저장과 예외

- 불가 사유와 우회 경로는 파생 정보이므로 저장하지 않는다.
- 기존 저장에 없는 진단 필드는 필요하지 않으며 원본 자료도 변경하지 않는다.
- 시전자 행동 완료·혼란 등 부대 자체의 이동 불가는 목적지 문제와 분리한다.
- 지도 밖·잘못된 좌표·미지원 데이터는 각각 명시적으로 처리한다.
- 우회 가능성이 검증되지 않으면 새 경로를 그리거나 다음 턴 도달을 보장하지 않는다.
- 진단은 실제 이동 원점·위치·플래그·RNG·로그를 바꾸지 않는다.

## 완료 기준

- [ ] 예산 부족·통행 불가·아군 도착 점유·공개 적 점유가 구분된다.
- [ ] 아군 통과, 시작점의 적 방해 탈출, 방해 예외 플래그를 실제 규칙과 동일하게 처리한다.
- [ ] 여러 제약이 겹칠 때 증명 가능한 사유만 안정된 순서로 제시한다.
- [ ] 숨겨진 적을 달리 배치한 사례에서 설명이 정체·방향·좌표를 드러내지 않는다.
- [ ] 제시한 우회 경로는 실제로 합법적이며 조회 전후 상태·RNG가 동일하다.
- [ ] 실제 창에서 hover·클릭·취소·상태 변화 뒤 안내가 올바르게 갱신된다.

## 작업 순서

1. 실제 이동 판정의 이유 코드와 공개 가능 조건을 정리한다.
2. F2 진단과 기존 경로 결과의 일치 검증을 만든다.
3. 이동 커서·클릭 거부 메시지와 합법 우회 표시를 연결한다.
4. 합성 점유·지형·숨김 사례 및 실제 창을 별도로 검증한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

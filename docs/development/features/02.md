# 02. 위험도 지도와 개별 적 위협 고정

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P1 · 단계: M1
- 선행조건: F1 읽기 전용 예측, F2 규칙 조회. 01·18·27과 같은 기반을 공유하되 상호 완료 의존은 없다.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [OriginalBattle.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattle.swift)의 `threatCells`는 공개된 적의 이동 후 일반 공격 칸을 합친다.
- 해당 함수는 책략과 AI 명령을 계산하지 않는다고 명시한다.
- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `drawThreat`는 단일 집합을 한 색으로 표시한다.
- 추가 기능은 부대별 위협 출처, 겹치는 적의 수, 책략 위험과 특정 적 고정을 제공한다.

## 목적과 화면 흐름

1. 기존 적 위협 버튼에서 일반 공격·책략 위험 표시를 선택한다.
2. 한 칸을 가리키면 그 칸을 공격할 수 있는 공개된 적의 수와 이름을 본다.
3. 적 하나를 고정하면 전체 지도 표시와 별도로 그 부대의 위협만 강조한다.
4. 설명에는 ‘현재 공개 정보로 계산한 이동 후 공격 가능 범위’를 사용한다.
5. 실제 AI의 다음 행동·타깃을 확정적으로 예고하지 않는다.

## 구현 범위와 진입점

- 신규 타입 제안 `ThreatMap`은 칸별 일반 공격 출처 집합과 책략 출처 집합을 보관한다.
- 출처는 runtime slot, 장수 ID, 행동 ID, 가능한 기점 집합으로 구성하며 같은 적을 중복 집계하지 않는다.
- `threatCells`의 단일 합집합 앞 단계에서 출처를 보존하고 `drawThreat`가 이를 렌더링한다.
- 적 이동과 일반 공격은 기존 이동·사거리 규칙을 사용하고 책략은 F2의 병과·레벨·MP·날씨·지형 제한을 따른다.
- 현재 병력·MP에서 가능한 위협과 다음 턴 회복 여부가 미확정인 위협을 구분한다.
- 상태 이상으로 행동이 불가한 적은 현재 위협에서 제외하며, 회복 가정을 몰래 적용하지 않는다.
- ‘책략 가능’은 효과 성공을 뜻하지 않는다. 확률이 있으면 상세에서 별도 표시한다.
- 공개 여부가 없는 적과 미래 이벤트의 부대는 계산 결과에도 포함하지 않는다.
- 숨겨진 점유나 이동 방해로 적 위치가 간접 노출될 수 있는 칸은 확정 안전으로 표시하지 않는다.
- 캐시 키는 위치뿐 아니라 병과·레벨·MP·날씨·지형·상태·공개 여부의 변경을 포함한다.

## 저장과 예외

- 전체 계산 결과는 파생 데이터로 저장하지 않는다.
- 고정 적은 중단 저장의 선택적 UI 필드로만 보존할 수 있으며, 지도 ID·장수 ID·slot을 재검사한다.
- 이전 저장에 고정 정보가 없으면 고정 없음으로 시작하고 현재 전장으로 다시 계산한다.
- 대상 퇴각·비공개 전환·지도 변경 시 고정을 해제하고 잘못된 다른 적으로 연결하지 않는다.
- 고정/해제/필터 전환은 실제 상태·이벤트·RNG·행동 순서를 바꾸지 않는다.
- 범위 밖을 ‘절대 안전’으로 쓰지 않고 포함되지 않은 미래 변화의 한계를 안내한다.

## 완료 기준

- [ ] 한 적의 여러 공격 위치가 겹쳐도 해당 칸의 적 수는 한 번만 증가한다.
- [ ] 두 적의 중첩, 일반 공격·책략 중첩과 선택 적 고정이 구분된다.
- [ ] MP·날씨·혼란·지형 변화 뒤 캐시가 갱신되어 오래된 위협이 남지 않는다.
- [ ] 숨겨진 적·증원 조건이 위험도나 이름 목록으로 노출되지 않는다.
- [ ] 조회 전후 실제 세션·RNG·기록이 동일하고 고정 적의 퇴각이 안전하게 처리된다.
- [ ] 실제 창에서 숫자·무늬·강조와 원래 이동 범위의 가독성을 함께 확인한다.

## 작업 순서

1. 공개 정보 규칙과 위협의 시간 기준을 F1/F2에 정의한다.
2. 출처를 유지하는 일반 공격·책략 집계를 구현한다.
3. 숫자 표시, 고정, 상세 목록과 저장 복원 규칙을 연결한다.
4. 합성 중첩·상태 변화·숨김 사례와 실제 화면을 별도로 검증한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

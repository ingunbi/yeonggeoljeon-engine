# 25. 부상한 장수를 회복할 방법 찾기

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P1 · 단계: M1
- 선행조건: [01 이동 전 예측](01.md), [09 사용 불가 이유](09.md), F1/F2.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `legalStrategyTargets`는 시전자와 책략을 고른 뒤 대상을 찾는다.
- [OriginalItems.swift](../../../Sources/YeonggeoljeonEngine/OriginalItems.swift)의 `targetSlots`·`begin`은 도구 범위와 실제 사용 조건을 검사한다.
- [OriginalCombat.swift](../../../Sources/YeonggeoljeonEngine/OriginalCombat.swift)의 `healingUseful`·`heal`은 회복 필요 여부·상한·효과를 계산한다.
- 추가 기능은 회복받을 장수를 먼저 고른 다음 이번 턴 가능한 수단을 역으로 찾는다.

## 목적과 화면 흐름

1. 아군 정보에서 ‘회복할 방법 찾기’를 연다.
2. 병력·사기·혼란 회복 탭에서 현재 필요한 효과를 선택한다.
3. 후보 장수, 책략/도구, 이동 위치, 회복량 범위, MP·물품 소모를 비교한다.
4. 후보를 누르면 기존 이동/명령 선택으로 이어지고 대상은 다시 확인한다.
5. 아무 수단이 없으면 현재 행동·MP·거리 등 확인 가능한 이유를 보여준다.

## 구현 범위와 진입점

- 신규 타입 제안 `RecoveryOption`은 대상 ID, 시전자 ID, 행동 종류, 도착점·경로, 회복 범위와 비용을 가진다.
- 현재 수동 행동 가능한 아군을 조회하고 01의 합법적 이동 위치를 계산한다.
- 책략은 실제 습득·MP 조건과 대상 검사를, 도구는 소지·범위·회복 조건을 F2로 재사용한다.
- 이동을 마친 장수는 현재 위치만 후보로 제공한다.
- 병력·사기 증가량은 상한 적용 뒤의 실제 범위로 표시하고 서로 다른 단위를 합산하지 않는다.
- 혼란 해제는 확률 또는 조건부 효과로 표시하며 병력 회복만으로 반드시 풀린다고 안내하지 않는다.
- 자기 자신에게 쓰는 수단, 다른 장수의 단일 회복, 범위 회복을 구분한다.
- 동일 행동에 여러 도착점이 있으면 최소 이동 비용 등 명시한 기준으로 대표 위치를 고르고 전체 후보도 열어볼 수 있게 한다.
- 여러 장수의 연속 회복 계획이나 다음 턴 자동 회복은 이번 턴 단일 행동 검색과 분리한다.
- 예측 문자열을 파싱하지 않고 F1의 구조화된 회복 결과를 사용한다.

## 저장과 예외

- 검색 결과·가상 경로는 저장하지 않으며 불러오기 후 현재 상태로 다시 찾는다.
- 검색·정렬·선택만으로 MP·소지품·이동·RNG·기록이 변경되지 않는다.
- 대상 퇴각·상태 회복·위치 변경이나 시전자 행동 종료 시 후보를 무효화한다.
- 실행 전에는 실제 명령 진입점에서 비용과 대상 조건을 다시 검사한다.
- 숨겨진 점유나 적 위치를 ‘이 경로만 막힘’ 같은 상세 사유로 드러내지 않는다.
- 회복 상한 초과 병력이 조정되는 예외는 증가량으로 위장하지 않고 병력 조정으로 표시한다.

## 완료 기준

- [ ] 대상 우선 검색 결과가 시전자 우선의 실제 사용 가능 조건과 일치한다.
- [ ] 자신·단일·범위 회복, 행동 완료, MP/소지품 부족, 이동 후 사거리를 구분한다.
- [ ] 병력·사기 상한과 혼란 해제 확률을 올바른 단위·조건으로 표시한다.
- [ ] 검색 반복과 후보 선택 취소가 실제 상태·RNG·기록을 바꾸지 않는다.
- [ ] 검색 이후 상태가 변하면 오래된 후보로 자동 사용하지 않는다.
- [ ] 실제 창에서 후보 비교→이동→기존 대상 확인 흐름을 확인한다.

## 작업 순서

1. 대상 필요 효과와 F1/F2 회복 후보 계약을 정의한다.
2. 현재 위치 검색부터 구현하고 01의 이동 후보를 연결한다.
3. 비용·효과 비교와 09의 불가 사유, 기존 명령 진입을 통합한다.
4. 합성 회복 경계와 실제 창에서 실행 전 재검사를 검증한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

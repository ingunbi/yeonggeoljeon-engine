# 01. 이동 전 공격과 책략 미리보기

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P1 · 단계: M1
- 선행조건: F1 읽기 전용 예측, F2 규칙 조회 계약. 02·18·27의 기능 완료를 기다리지 않는다.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `drawField`는 이동 가능 칸과 커서까지의 경로를 표시한다.
- 같은 파일의 `drawForecasts`는 공격·책략 명령을 선택한 뒤 현재 위치의 대상별 예측을 표시한다.
- [OriginalBattle.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattle.swift)의 `route`, `attackForecast`, `strategyForecast`를 연결할 기반이 있다.
- 추가 기능은 이동을 확정하기 전에 가상 도착 위치를 기준으로 도달 가능한 대상을 읽는 것이다.

## 목적과 화면 흐름

1. 행동 가능한 아군을 고르고 이동할 칸에 커서를 놓는다.
2. 경로와 함께 일반 공격 대상, 선택한 책략의 유효 대상, 사거리를 구분해 표시한다.
3. 회복 책략은 아군·자신을 대상으로 표시하고, 공격과 회복 표시를 색과 형태로 구분한다.
4. 일반 공격/책략 선택을 바꿔 비교한 뒤 기존 이동 클릭으로 위치를 확정한다.
5. 미리보기 선택만으로 이동이나 공격이 실행되지 않는다.

## 구현 범위와 진입점

- `drawField`의 `.moving(slot)`과 `hoveredCell`을 입력으로 사용한다.
- 신규 타입 제안 `MoveActionPreview`는 부대 식별자, 가상 위치, 경로, 행동 종류, 유효 대상, 예상 효과를 가진다.
- F1에서 위치만 바꾼 값 스냅샷을 만들고 실제 `session.move`는 호출하지 않는다.
- 이동 가능성은 기존 `reachable`·`route`, 사거리는 `OriginalAI.attackCells`·책략 대상 규칙을 재사용한다.
- 대상의 날씨·지형·병력 회복 가능 여부는 F2로 조회한다. UI에서 원본 수식을 다시 작성하지 않는다.
- 기존 문자열형 책략 예측은 F1의 구조화된 피해·회복·성공 확률로 연결하고, 문자열을 역파싱하지 않는다.
- 예측 가능 대상만 보이며, 미래 증원·숨겨진 적의 정체와 위치는 표시하지 않는다.
- 실패 확률이 있는 책략은 성공 시 피해와 성공 확률을 나누고, 현재 RNG의 다음 결과를 공개하지 않는다.
- 스크립트가 영향을 줄 수 있는 후속 효과는 확정 수치가 아닌 현재 배치 기준으로 표기한다.
- 계산 결과는 전투 상태 revision·부대·도착점·행동 ID로 캐시하고, 변경 시 이전 결과를 버린다.

## 저장과 예외

- 커서 위치, 임시 경로와 계산 캐시는 저장하지 않고 재개 시 다시 계산한다.
- 별도 미리보기 표시 설정을 저장한다면 누락된 이전 설정은 기본값을 사용한다.
- 실제 상태, MP, 물품, 행동 플래그, 이동 원점, 전투 로그, RNG는 조회 전후 동일해야 한다.
- 사거리 밖·이동 불가 칸은 ‘이 위치에서 예측 불가’로 처리하고 이전 대상 표시를 지운다.
- 이동 후 실제 대상 선택에서는 기존 명령 경로가 최신 조건을 재검사한다.
- 원작 세이브와 원본 자료에는 데이터를 추가하지 않는다.

## 완료 기준

- [ ] 같은 위치에서 미리보기와 이동 후 명령의 유효 대상 집합이 합성 입력에서 일치한다.
- [ ] 화계의 비·지형 제한, 회복이 필요 없는 대상, 자신 대상 책략을 구분한다.
- [ ] 여러 칸을 반복 조회해도 실제 상태·RNG·이동 원점·기록이 변하지 않는다.
- [ ] 숨겨진 적을 바꾸어도 공개 가능한 표시가 적의 위치를 드러내지 않는다.
- [ ] 마우스 이동·책략 전환·Esc 취소 후 잔상이나 이전 위치의 수치가 남지 않는다.
- [ ] 실제 창에서 표시와 클릭 영역을 확인하고 고정 입력 검증과 별도 기록한다.

## 작업 순서

1. F1/F2 입력·결과 계약과 공개 정보 경계를 정의한다.
2. 가상 위치의 대상 조회와 구조화된 예측을 연결한다.
3. 이동 커서 UI·캐시 무효화·기존 확정 경로를 통합한다.
4. 합성 사례와 실제 창 조작을 검증하며, 원본 비교가 필요한 부분은 별도 한계로 기록한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

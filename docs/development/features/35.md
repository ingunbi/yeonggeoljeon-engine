# 35 두 장수 나란히 비교

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 우선순위: P2
- 개발 단계: M2
- 선행조건: F1 장수 정보 투영, F2 능력·책략 조회
- 기준일: 2026-11-09

## 목적과 현재 구현

출전 후보 두 명의 역할과 현재 능력 차이를 한 화면에서 비교한다. 현재 [OriginalCampaignView.swift](../../../Sources/YeonggeoljeonEngine/OriginalCampaignView.swift)의 `personDetail`은 한 장수의 정보를, [StrategyLearningGuide.swift](../../../Sources/YeonggeoljeonEngine/StrategyLearningGuide.swift)는 한 병과의 습득표를 보여준다.

## 사용 흐름과 화면

1. 장수 목록이나 편성 화면에서 첫 장수를 비교 대상으로 고정한다.
2. 두 번째 장수를 선택해 좌우 카드로 비교한다.
3. 능력·이동·공격 범위·배운 책략·소지품 탭을 바꿔 본다.
4. 좌우 교환, 다른 후보 선택, 원래 목록으로 돌아가기를 제공한다.
5. 비교 화면 자체에서 출전 확정이나 물품 이동은 수행하지 않는다.

## 구현 범위와 데이터

- 제안 타입 `OfficerComparison`은 두 인물 ID와 같은 시점의 읽기 전용 능력 스냅샷을 가진다.
- [OriginalState.swift](../../../Sources/YeonggeoljeonEngine/OriginalState.swift)의 `stats`와 현재 책략 습득 규칙을 재사용한다.
- 레벨·사기·장비 조건을 각각 표시한다. 단순 차이를 두 장수의 본질적인 우열 점수로 해석하지 않는다.
- 필드에서는 공통 사기 기준을, 전투에서는 각 장수의 현재 사기를 표시한다.
- 범위는 격자 모양을 비교하고 이동력은 지형별 비용 링크를 제공한다.
- 전직 전후 비교는 11번, 물품 이전 전후 비교는 14번으로 연결한다.

## 저장과 호환

비교 고정 장수와 탭은 화면 상태로 둔다. 저장에는 인물 데이터만 기존 방식으로 남긴다. 불러오기나 장수 이탈 시 비교 대상을 다시 검증하고 참가하지 않은 장수를 자동 노출하지 않는다.

## 예외와 취소

동일 장수 두 명을 선택하면 동일 대상임을 표시하거나 두 번째 선택을 요청한다. 자료가 부족한 수치는 0으로 대체하지 않는다. 창이 좁으면 두 카드를 탭으로 전환하되 같은 항목 위치를 유지한다.

## 완료 기준

- [ ] 각 장수의 수치가 개별 정보 화면과 일치한다.
- [ ] 비교 기준인 레벨·사기·장비가 명확히 드러난다.
- [ ] 책략 목록은 실제 현재 병과와 레벨을 반영한다.
- [ ] 좌우 교환과 후보 변경이 인물 상태·편성·난수를 바꾸지 않는다.
- [ ] 장수 이탈·불러오기 후 오래된 비교가 남지 않는다.

## 작업 순서

공유 장수 스냅샷 → 같은 항목의 좌우 배치 → 목록·편성 진입 → 좁은 창 배치 → 개별 화면과 값 비교 순서로 진행한다.

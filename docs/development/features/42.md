# 42 장수와 물품 및 책략 통합 검색

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 우선순위: P3
- 개발 단계: M4
- 선행조건: F6 공개 정보 색인, F5 검색 입력, 기존 인물·소지품 읽기 전용 조회
- 기준일: 2026-11-09

## 목적과 현재 구현

이름을 몰라도 ‘혼란 회복’, ‘범위 공격’ 같은 효과로 관련 정보를 찾는다. 현재 장수는 [OriginalCampaignView.swift](../../../Sources/YeonggeoljeonEngine/OriginalCampaignView.swift)의 `presentPeople`, 책략은 [StrategyLearningGuide.swift](../../../Sources/YeonggeoljeonEngine/StrategyLearningGuide.swift)의 목록으로 따로 조회한다.

## 사용 흐름과 화면

1. 게임 메뉴에서 정보 검색을 열고 이름 또는 효과를 입력한다.
2. 장수·물품·책략 유형별 결과를 보고 보유·습득 여부로 좁힌다.
3. 결과를 선택하면 기존 상세 화면으로 이동한다.
4. 뒤로 돌아오면 검색어와 결과 위치가 유지된다.
5. 검색 결과에서 실제 행동을 바로 실행하지 않는다.

## 구현 범위와 데이터

- 제안 타입 `GameInfoIndexEntry`는 종류, 안정적인 ID, 표시 이름, 구조화 효과 태그, 공개 근거, 상세 연결을 가진다.
- [StrategyGuideDetails.swift](../../../Sources/YeonggeoljeonEngine/StrategyGuideDetails.swift)와 물품 실행 종류의 확인된 효과를 태그로 변환한다.
- 초판은 이름 부분 일치와 명시적인 동의어·효과 태그 검색을 지원한다. 외부 AI나 인터넷 검색에 의존하지 않는다.
- 공개 가능한 현재 장수·보유 물품·관측 정보·기존 습득표 범위만 색인한다. 원본 데이터에 있다는 이유만으로 숨겨진 장수를 노출하지 않는다.
- ‘가지고 있음’, ‘현재 습득’, ‘향후 습득’은 정보를 찾는 필터이며 이번 턴 사용 가능성을 보장하지 않는다.
- 25번 회복 수단 찾기는 실제 행동 가능성 계산을, 이 기능은 일반 정보 탐색을 담당한다.

## 저장과 호환

색인은 로컬 데이터셋과 공개 정보 상태에서 재생성하는 캐시다. 저장 파일에는 색인 전체를 넣지 않는다. 공개 근거가 되는 회차 관측은 F3를 사용하고, 불러오기 후에는 그 시점의 공개 범위로 색인을 교체한다.

## 예외와 취소

검색 입력 중 게임 단축키가 실행되지 않게 한다. 같은 이름은 유형·장수·출처를 함께 표시한다. 알 수 없는 효과 태그는 추측하지 않는다. 자료 변경·전직·물품 소진 후에는 오래된 보유·습득 표시를 갱신한다.

## 완료 기준

- [ ] 이름과 명시적인 효과 태그로 원하는 유형의 정보를 찾을 수 있다.
- [ ] 미공개 장수와 미래 관측 정보가 결과나 건수로 새지 않는다.
- [ ] 보유·습득 표시가 현재 상태와 일치한다.
- [ ] 상세 화면 왕복에서 검색어·선택 위치를 유지한다.
- [ ] 검색·필터·상세 조회가 게임 상태와 난수를 바꾸지 않는다.

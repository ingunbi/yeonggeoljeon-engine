# 24. 적 턴 종료 후 변화 요약

- 작성일: 2026-11-09
- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 우선순위: P2 · 단계: M3
- 선행: 공통 F4 확정 이벤트, F3 확장 저장. [10번](10.md)과 사건 식별·중복 제거를 공유한다.
- 공통 기준: [구조와 데이터](../architecture.md), [검증 계획](../verification.md)

## 현행과 차이

- [OriginalTurns.swift](../../../Sources/YeonggeoljeonEngine/OriginalTurns.swift)의 `prepareEnemyPhase`, `completeRound`, `enterManualFriendly`가 턴 경계를 구분한다.
- [OriginalBattleFlow.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleFlow.swift)의 `drivePhases`는 행동·이벤트·퇴각 처리와 연출 대기를 연결한다.
- [BattleResultLog.swift](../../../Sources/YeonggeoljeonEngine/BattleResultLog.swift)의 기존 로그에는 개별 확정 결과가 있으나 모든 스크립트 상태 변화가 포함되지는 않는다.
- [OriginalScriptBattle.swift](../../../Sources/YeonggeoljeonEngine/OriginalScriptBattle.swift)의 `applyScriptAttribute` 등 직접 변화도 다루어야 하므로 상세 로그만 단순 합산하지 않는다.

## 목적과 화면 흐름

1. 적 턴이 끝나고 다음 수동 명령 경계가 오면 `지난 적 턴` 요약을 짧게 표시한다.
2. 아군 병력 감소·회복·혼란 변화·퇴각·실제로 공개된 증원을 묶어 보여준다.
3. 항목을 누르면 해당 부대 또는 마지막으로 공개된 위치를 확인한다.
4. 자동 표시를 끌 수 있고 메뉴에서 최근 요약을 다시 열 수 있게 한다.
5. 전투가 종료되면 다음 아군 차례가 있는 것처럼 안내하지 않고 [10번](10.md)의 결과와 연결한다.

## 구현 설계와 데이터

- 새 제안 타입 `EnemyPhaseSummary`에 battle/attempt ID, round ID, 사건 범위, 부대별 전후 값과 출처를 둔다.
- 적 AI 시작 직전에 공개 상태 기준선을 잡고 다음 수동 입력 직전의 확정 상태와 비교한다.
- 적 행동 뒤 이어지는 턴 시작 회복·날씨·스크립트 변화는 `다음 차례 시작`으로 별도 묶어 인과를 구분한다.
- F4 이벤트 ID로 공격·책략·도구·스크립트 변화를 한 번만 소비한다.
- 전후 비교는 누락 탐지와 최종 값 확인에 사용한다. 같은 병력 변화를 이벤트 합산과 상태 차이로 두 번 더하지 않는다.
- 원인을 알 수 없는 차이는 `이벤트로 변경` 또는 `변화 원인 미기록`으로 표시하고 공격자로 추측하지 않는다.
- 병력 순감소와 받은 피해·회복 합계를 구분하여 회복 뒤 재피해를 숫자 하나로 오해하지 않게 한다.
- 퇴각 부대는 남아 있는 unit 슬롯에 잘못 연결하지 않도록 인물 ID와 당시 공개 위치를 함께 기록한다.
- `OriginalBattleView.announcePhase` 부근에서 완성된 요약을 제시하되 렌더링 횟수로 생성하지 않는다.
- 설정은 자동 표시만 바꾸며 집계와 전투 결과는 동일하게 유지한다.

## 저장·호환·오류·취소

- 최근 완료 요약과 필요한 집계 커서를 F3에 저장하고 중단 재개 시 같은 적 턴 요약을 중복 생성하지 않는다.
- 현재 저장 경계는 적 턴이 끝날 때까지 기다리므로 진행 중 적 AI의 사적 실행 상태를 새로 저장하지 않는다.
- 이전 저장에 요약이 없으면 `이전 변화 기록 없음`으로 표시하고 전투 시작 수치에서 역산하지 않는다.
- 새 전투·재시작에는 해당 전투 요약을 초기화한다. 과거 저장 복원 뒤 미래 턴 기록을 합치지 않는다.
- 숨은 부대·미등장 증원·미공개 좌표는 전후 비교 결과에 있어도 화면에 노출하지 않는다.
- 창 닫기·항목 선택 취소는 카메라·표시 상태만 바꾸며 명령·난수를 소모하지 않는다.

## 완료 기준

- [ ] 공격·회복·혼란 해제·퇴각·스크립트 변화가 각 한 번 집계되고 전후 최종 값이 실제 상태와 같다.
- [ ] 적 턴 변화와 다음 차례 시작 회복·이벤트가 구분되어 표시된다.
- [ ] 퇴각한 장수 항목을 선택해도 재사용된 슬롯의 다른 장수로 이동하지 않는다.
- [ ] 숨겨진 증원과 미공개 위치가 요약에 나타나지 않는다.
- [ ] 중단 재개·표시 끄기·전투 종료·재시작에서도 중복 요약과 게임 상태 변경이 없다.

## 작업 순서

1. 적 턴과 다음 수동 경계의 사건 범위 및 공개 상태 기준을 정의한다.
2. F4 집계·전후 검산·중복 제거를 합성 상태로 검사한다.
3. 요약 패널과 지도 이동을 붙이고 F3 최근 요약 복원을 연결한다.
4. [08번](08.md) 정상 플레이의 적 턴·퇴각·증원 경로로 대조한다.

# 28. 이어하기 직후 진행 요약

- 작성일: 2026-11-09
- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 우선순위: P2 · 단계: M3
- 선행: 상태 기반 최소 요약은 단독 가능. 최근 선택 보강은 F3·F4 및 [29번](29.md) 기록이 있을 때 적용한다.
- 공통 기준: [구조와 데이터](../architecture.md), [검증 계획](../verification.md)

## 현행과 차이

- [OriginalCampaignView.swift](../../../Sources/YeonggeoljeonEngine/OriginalCampaignView.swift)의 `resumeDetail`은 저장 목록에서 장·장소·레벨·소지금·일행을 보여준다.
- 같은 파일의 `resumeSuspended`, `loadThroughFade`는 복원한 호스트와 화면을 교체한다. 이어하기 직후의 별도 요약은 없다.
- [OriginalCampaignHost.swift](../../../Sources/YeonggeoljeonEngine/OriginalCampaignHost.swift)의 `OriginalCampaignResume`은 일반·전투 시작·중단 저장을 구분한다.
- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `readyUnits`, `showConditions`는 남은 행동 부대와 현재 승리조건의 기존 진입점이다.

## 목적과 화면 흐름

1. 불러오기 성공 뒤 `이어서 할 일` 패널에 현재 장소 또는 전투, 턴, 공개 목표와 남은 행동 부대를 보여준다.
2. 전투 시작 저장이면 `첫 턴부터 재개`, 중단 저장이면 `중단 지점부터 재개`를 명확히 표시한다.
3. 마을·세계지도에서는 현재 장소와 실제 대기 중인 선택·대화 여부를 안내한다.
4. 최근 선택 기록이 있으면 마지막 3개까지만 표시하고 자세한 내용은 여정 화면으로 연결한다.
5. `계속`을 누르면 원래 대사·선택·명령 경계로 돌아간다. 자동 표시 여부는 설정으로 조절한다.

## 구현 설계와 데이터

- 새 제안 타입 `ResumeBrief`는 복원된 호스트에서 읽기 전용으로 만드는 표시 모델이다.
- 장소·전투 ID·현재 턴·공개 목표·행동 가능한 아군 수는 실제 복원 상태에서 계산한다.
- 남은 행동 수는 화면의 기존 합법 입력 판정과 같은 조건을 사용하고 단순 생존자 수로 대체하지 않는다.
- 목적을 확인할 수 없는 장면은 `대사 진행 중` 또는 `선택 대기`로 표시한다. 다음 줄의 스토리를 미리 해석하지 않는다.
- 최근 선택은 F4의 실제 확정 사건과 F3에 저장된 여정에서만 읽는다. 기록이 없으면 해당 영역을 생략한다.
- 공통 `afterSuccessfulResume` 표시 훅은 새 제안이며 `resumeSuspended`와 일반·원작 파일 불러오기 경로를 하나로 연결한다.
- 복원 검증과 중단 파일 소모가 끝난 뒤 패널을 띄운다. 패널 실패를 복원 실패로 오인해 파일을 되살리지 않는다.
- 요약을 보이는 동안 기존 대사 타이머와 자동 넘김을 잠시 멈추고 닫을 때 남은 시간과 입력 초점을 되돌린다.
- 동일 로드에서 화면 재배치·리사이즈가 일어나도 한 번만 자동 표시한다.

## 저장·호환·오류·취소

- 현재 상태로 계산 가능한 요약은 저장하지 않는다. 최근 선택 등 추가 기록만 F3로 게임 저장과 함께 커밋한다.
- 일반 저장의 메타데이터만 믿지 않고 실제 복원된 상태를 표시하므로 오래된 제목과 현재 장소가 혼동되지 않는다.
- 예전 자체 저장과 원작 저장에는 알 수 있는 현재 정보만 표시하고 과거 선택을 추정하지 않는다.
- 과거 저장 복원 때 이후 여정·전투 결과가 유입되지 않게 해당 저장의 기록만 사용한다.
- 부가 요약을 만들 수 없어도 검증된 게임 복원 자체는 유지하며 짧은 안내 후 기존 화면으로 진행한다.
- 취소·Esc는 요약만 닫는다. 중단 저장 1회 소모를 취소하거나 재사용 가능하게 만들지 않는다.
- 숨은 목표·미공개 장수·미래 증원은 요약에 넣지 않는다.

## 완료 기준

- [ ] 일반·전투 시작·중단·원작 저장별 실제 재개 위치와 의미가 정확히 표시된다.
- [ ] 남은 행동 수와 공개 목표가 현재 전투의 기존 판정·화면과 일치한다.
- [ ] 예전 저장은 없는 최근 선택을 만들지 않으며 [29번](29.md) 없이도 최소 요약이 동작한다.
- [ ] 요약 닫기 후 대사·선택·남은 표시 시간과 키보드 초점이 복원된다.
- [ ] 중단 파일은 한 번만 소모되고 요약 표시 실패·재표시가 게임 복원이나 난수에 영향을 주지 않는다.

## 작업 순서

1. 복원 상태만으로 만드는 최소 표시 모델과 저장 종류별 문구를 구현한다.
2. 성공한 모든 불러오기 경로의 공통 표시 훅과 타이머 보존을 연결한다.
3. F3·F4·[29번](29.md)이 준비되면 실제 최근 선택만 추가한다.
4. 예전 저장·선택 대기·대사 중·이동 취소 가능 상태에서 재개 검사를 수행한다.

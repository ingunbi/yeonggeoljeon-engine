# 19. 지도 메모와 작전 표시

- 작성일: 2026-11-09
- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 우선순위: P3 · 단계: M4
- 선행: 공통 F3 확장 저장. [21번](21.md)의 지도 배율과 좌표 변환 기준을 공유한다.
- 공통 기준: [구조와 데이터](../architecture.md), [검증 계획](../verification.md)

## 현행과 차이

- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `canvasPoint`, `drawThreat`는 입력 좌표와 지도 범위 표시를 다룬다.
- [OriginalBattle.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattle.swift)의 `scriptActions`에는 원작 스크립트의 지도 상태가 있고 `suspensionState`가 이를 보존한다.
- [RuntimeSuspend.swift](../../../Sources/YeonggeoljeonEngine/RuntimeSuspend.swift)의 `OriginalBattleSuspension`에는 사용자 작전 메모가 없다.
- 새 메모는 엔진 편의 정보이며 원작 스크립트 표식·지형·이동 가능 여부를 수정하지 않는다.

## 목적과 화면 흐름

1. 전투 메뉴의 `작전 메모`에서 핀·방어선·화살표·짧은 메모를 고른다.
2. 지도 칸을 찍거나 시작·끝 칸을 지정한 뒤 내용과 색·무늬를 확인한다.
3. 메모 목록에서 항목을 선택하면 위치로 이동하고 편집·삭제할 수 있다.
4. 표시 전체 켜기·끄기와 현재 전투 메모 지우기를 제공한다.
5. 메모 입력 중에는 공격·이동 명령이 실행되지 않으며 Esc로 작성만 취소한다.

## 구현 설계와 데이터

- 새 제안 타입 `BattleAnnotation`에 UUID, battle ID, attempt ID, 종류, 지도 좌표, 텍스트, 표시 순서를 둔다.
- 위치는 화면 픽셀이 아니라 `GridPoint`로 저장하고 `OriginalBattleView`의 카메라 변환으로 그린다.
- 새 제안 타입 `AnnotationEditorState`로 시작점 대기·끝점 대기·문자 입력·확정 상태를 구분한다.
- 메모는 80자, 한 전투 100개를 초기 상한으로 제안한다. 상한 초과는 저장 전에 알린다.
- 선·화살표는 양 끝점을 저장하고 지도 바깥 좌표를 거부한다. 장수 추적형 핀은 첫 범위에 포함하지 않는다.
- 지도 위 표식은 부대 선택·책략 범위·승리조건과 겹쳐도 구별되게 무늬와 라벨을 제공한다.
- 실제 지도 배율·스크롤·창 크기가 바뀌면 같은 칸에 붙어 있어야 한다.
- 원작 `scriptActions.markers`에 메모를 끼워 넣지 않고 UI 전용 계층에서 합성한다.
- 편집 가능 시점은 수동 입력 경계로 제한한다. 조회는 게임 행동을 진행시키지 않는다.

## 저장·호환·오류·취소

- F3의 진행 종속 데이터로 중단 저장과 같은 원자적 커밋에 보관한다. 독립 sidecar는 두지 않는다.
- 같은 전투를 중단 후 이어하면 유지한다. 새 전투 진입 때 빈 메모로 시작한다.
- 전투 재시작은 새 attempt ID이므로 초기화하고, 남기고 싶으면 재시작 확인 전에 그 의미를 안내한다.
- 이전 저장을 불러오면 그 시점 메모로 돌아간다. 다른 분기나 나중 저장의 메모를 합치지 않는다.
- 예전 저장은 메모 없음으로 읽는다. 유효하지 않은 좌표·종류·크기는 명확한 오류로 처리한다.
- 작성 취소는 임시 메모를 버릴 뿐 이미 저장된 메모와 게임 상태를 바꾸지 않는다.
- 지도 표시는 확인된 지도에만 붙이며 메모 기능이 숨은 부대나 미공개 이벤트 정보를 생성하지 않는다.

## 완료 기준

- [ ] 핀·메모·화살표 작성·편집·삭제·취소가 실제 이동·공격과 충돌하지 않는다.
- [ ] 스크롤·창 크기·지도 배율을 바꿔도 표식이 같은 지도 칸에 남는다.
- [ ] 중단 저장 재개 시 유지되고 새 전투·재시작·과거 저장 복원 시 정의한 범위대로 초기화된다.
- [ ] 글자·항목 수·지도 경계 제한을 검사하고 잘못된 데이터를 원작 지도 표식으로 적용하지 않는다.
- [ ] 메모 표시 여부와 편집 전후의 게임 상태·난수·행동 여부가 동일하다.

## 작업 순서

1. 지도 좌표 모델과 전투·시도별 수명주기를 합성 검사로 고정한다.
2. 표식 계층·편집 모드·목록과 입력 취소를 구현한다.
3. F3 중단 저장 복원과 배율별 좌표 검사를 연결한다.
4. 겹치는 부대·범위·메모의 가독성과 키보드 접근을 확인한다.

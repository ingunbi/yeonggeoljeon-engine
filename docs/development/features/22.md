## 목적과 현재 구현

사용자가 읽기 편한 글자와 구별 가능한 범위 표시, 익숙한 키를 선택한다. 현재 [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `keyDown`은 키코드를 직접 처리하고, [CanvasTheme.swift](../../../Sources/YeonggeoljeonEngine/CanvasTheme.swift)의 글자 크기·색은 고정값을 사용한다.

## 사용 흐름과 화면

1. 환경 설정의 조작·가독성에서 키 배치, 글자 크기, 범위 표시를 조절한다.
2. 키 변경은 명령을 선택한 뒤 새 조합을 입력하고 충돌을 확인한다.
3. 글자 크기와 색·무늬는 샘플 목록과 전장 미리보기에 즉시 반영한다.
4. 항목별 기본값 복원과 전체 복원을 제공한다.
5. 설정을 닫으면 현재 대사와 선택 상태를 유지한다.

## 구현 범위와 데이터

- 제안 타입 `InputBinding`은 의미 명령 ID, 화면 문맥, 키·수정키 조합을 가진다.
- 지도·대사·목록·텍스트 입력 문맥을 구분해 같은 입력이 두 명령에 전달되지 않게 한다.
- 메뉴 막대 단축키와 화면 안내도 같은 바인딩을 사용한다. 시스템 예약 조합은 지정하지 못한다.
- 글자 크기는 초판 100·125·150%로 제한하고 행 높이·버튼·스크롤·본문 줄바꿈을 함께 계산한다.
- 이동·공격·지원·위협은 색상 외에도 선·점·사선 등 패턴으로 구별한다.
- 전체 VoiceOver 지원은 별도 범위이며, 이 문서의 완료로 주장하지 않는다.

## 저장과 호환

설정은 버전 있는 사용자 환경 값으로 저장한다. 이전 설정에 필드가 없으면 현행 키·크기·색을 사용한다. 초기 설정 읽기 중 알림을 재진입시키지 않고 전체 설정을 적용한 뒤 갱신한다.

## 예외와 취소

현재 입력 문맥에서 충돌하는 키는 저장하지 않는다. 검색창 입력 중 게임 명령은 차단한다. 작은 창에서는 큰 글자를 줄이는 대신 스크롤과 적응 배치를 사용한다. 손상된 개별 설정은 기본값으로 복구하고 이유를 안내한다.

## 완료 기준

- [ ] 키 변경 후 메뉴·도움말·실제 동작이 일치한다.
- [ ] 한 입력이 대사 넘기기와 전투 행동을 동시에 일으키지 않는다.
- [ ] 최대 글자 크기에서 버튼과 본문이 잘리지 않고 키보드로 접근된다.
- [ ] 단색 화면에서도 네 가지 범위를 패턴으로 구분할 수 있다.
- [ ] 이전 설정과 잘못된 바인딩을 읽어도 시작 실패나 재귀 알림이 없다.

# 20 중요한 전투 연출만 보기

- 우선순위: P2
- 개발 단계: M3
- 선행조건: F3 회차 확장 저장, F5 화면 명령 경계
- 기준일: 2026-11-09

## 목적과 현재 구현

반복 교전은 짧게 보고 원하는 장수의 교전과 일기토는 유지한다. 현재 [OriginalSettings.swift](../../../Sources/YeonggeoljeonEngine/OriginalSettings.swift)의 `unitCombat`은 확대 연출 전체 켜기·끄기다. [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `startCombat`, `presentHeld`가 확대 장면과 후속 연출을 연결한다.

## 사용 흐름과 화면

1. 전투 설정에서 확대 연출을 ‘전부 / 지정 장수 / 끔’ 중 선택한다.
2. 지정 장수 모드에서는 현재 아군 중 원하는 장수를 고른다.
3. 일기토는 별도 표시 설정으로 기본 유지한다.
4. 생략되는 확대 장면의 결과는 지도 위에서 표시한다.
5. 진행 중인 연출에 설정 변경을 적용할 때는 현재 장면을 마친 뒤 다음 장면부터 반영한다.

## 구현 범위와 데이터

- 제안 타입 `CombatPresentationPolicy`는 확대 연출 모드, 지정 인물 ID 집합, 일기토 표시 여부를 가진다.
- 장면의 확정된 공격자·대상 ID로 표시를 판단한다. 결과를 알아내려고 전투를 미리 실행하지 않는다.
- 정책은 표현 단계에만 적용한다. 실제 공격·반격·퇴각·스크립트 실행은 기존 흐름을 따른다.
- 원본 옵션워드와 새 표시 정책을 분리한다. [OriginalCombat.swift](../../../Sources/YeonggeoljeonEngine/OriginalCombat.swift)의 `physicalPrelude`는 일부 병과의 일반 공격에서 `sourceOptionsWord & 0xF0`에 따라 난수를 8회 또는 16회 소비한다. 새 연출 모드 변경은 이 옵션워드를 바꾸지 않는다.
- 현재 `OriginalBattleView.changeSetting`은 설정 변경 때 원본 옵션워드까지 갱신하므로, 새 표시 모드는 해당 쓰기 경로에서 분리한다. 생략된 표현에 필요했던 원본 규칙의 난수 소비는 그대로 수행한다.
- 확대 장면이 빠져도 후속 피해·레벨업·대사·지도 복귀 신호를 한 번씩 처리한다.
- ‘격파 장면만’처럼 결과가 미리 확정되어야 하는 옵션은 초판에 넣지 않는다.
- 배속, 건너뛰기, 적 이동 따라가기는 기존 별도 설정으로 유지한다.

## 저장과 호환

연출 모드는 사용자 설정에 저장하고, 지정 인물 목록은 F3의 회차 확장 데이터에 자료 식별값과 함께 저장한다. 과거 저장에는 해당 시점 목록만 복원한다. 이전 설정의 `unitCombat` 값은 새 표시 모드의 초기값인 전부 또는 끔을 정하는 데만 사용한다. 저장된 원본 옵션워드는 그대로 복원하고, 새 게임도 기존 생성 경로의 원본 옵션값을 유지한다. 표시 모드에서 원본 옵션값을 역산해 덮어쓰지 않는다.

## 예외와 취소

자료에 없는 인물 ID는 목록에서 제외하고 설정을 복구한다. 일기토 내부 대사와 이벤트는 연출 여부와 무관하게 처리한다. 지원되지 않는 장면은 기존 표시 경로로 돌아가며 전투 결과를 만들지 않는다.

## 완료 기준

- [ ] 같은 원본 옵션워드·시작 상태·입력에서 전부·지정 장수·끔의 최종 게임 상태와 난수가 일치한다. 원본 옵션이 다른 실행은 서로 다른 기준 경로로 검사한다.
- [ ] 생략한 장면의 피해·퇴각·레벨업·대사가 중복되거나 빠지지 않는다.
- [ ] 공격자 또는 대상이 지정 장수일 때 확대 장면을 보여준다.
- [ ] 연출 중 설정 변경과 중단 저장 예약이 진행을 멈추지 않는다.
- [ ] 이전 설정을 읽으면 기존 표시 선택이 유지된다.

## 작업 순서

원본 옵션워드와 표시 정책 분리 → 구형 설정 초기값 이주 → 장면 선택 → 후속 신호 보존 → 설정 화면 → 동일 원본 옵션·입력의 모드별 상태 비교 순서로 진행한다.

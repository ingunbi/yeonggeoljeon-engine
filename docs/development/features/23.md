# 23. 전투 목표 추적 패널

- 상태: 부분 구현 · 안정화 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P1 · 단계: M1
- 선행조건: 전투별로 출처를 확인한 공개 목표 자료와 현재 목표 상태의 읽기 경로.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `showConditions`는 목표 문자열과 현재/제한 턴을 창에 표시한다.
- [OriginalCampaignView.swift](../../../Sources/YeonggeoljeonEngine/OriginalCampaignView.swift)는 `board.objective`에 chapter와 `objectiveText`를 연결한다.
- [OriginalState.swift](../../../Sources/YeonggeoljeonEngine/OriginalState.swift)의 `OriginalBattleHeader`는 제한 턴과 이벤트용 목표 정보를 가진다.
- 추가 기능은 확인된 목표의 진행 상태를 작게 유지하지만 승패 판정을 새로 구현하지 않는다.

## 목적과 화면 흐름

1. 전투에 들어오면 작은 패널에 공개된 승리조건과 현재/제한 턴을 본다.
2. 조건별 상태는 미달성·확인됨·확인 불가를 구분한다.
3. 공개된 목표 장수를 누르면 현재 위치로 카메라를 옮긴다.
4. 패널을 접거나 기존 승리조건 창을 열 수 있다.
5. 새로운 목표가 실제로 공개되면 패널을 갱신한다.

## 구현 범위와 진입점

- 신규 타입 제안 `ObjectivePresentation`은 전투 ID, 공개 문구, 조건 ID, 상태, 공개 대상 ID, 출처 참조를 가진다.
- 원본 문자열을 자연어 파싱하거나 목표 장수 퇴각만 보고 승리를 추정하지 않는다.
- header의 eventKind는 이벤트 단서이지 곧바로 달성 상태가 아니다. 확인된 매핑만 구조화한다.
- [OriginalRetirement.swift](../../../Sources/YeonggeoljeonEngine/OriginalRetirement.swift)의 처리와 캠페인 VM 결과를 읽되 조회 때문에 이벤트를 dispatch하지 않는다.
- 매핑이 없는 전투는 원래 공개 목표 문구와 턴 수만 표시한다.
- 달성 체크는 확인된 상태 신호가 있을 때만 붙이며, 전투 결과는 기존 `turns.result`와 캠페인 처리를 따른다.
- 현재 턴은 `roundIndex + 1`이며 남은 턴을 표시할 경우 ‘현재 턴 포함’ 여부를 문구에 명시한다.
- 목표 대상 이동은 현재 살아 있고 공개된 일치 장수만 연결하며 slot 재사용을 검사한다.
- 숨겨진 목표·분기·증원·미확인 조건은 이름이나 조건 수로도 먼저 노출하지 않는다.
- 출처 오프셋과 확인 근거는 무시되는 로컬 분석 자료에 보관하고 정적 도출과 실행 비교를 구분한다.

## 저장과 예외

- 현재 달성 상태는 기존 캠페인 상태에서 재구성하고 별도의 승리 플래그를 저장하지 않는다.
- 패널 접기 설정만 사용자 설정으로 보관할 수 있다.
- 이전 저장에 구조화된 목표가 없으면 원래 문구와 턴 안내로 안전하게 복원한다.
- 목표 장수가 퇴각·비공개·교체되면 이동 버튼을 비활성화하고 이유를 표시한다.
- 목표 자료 불일치는 확인 불가로 표시하며 게임을 임의로 승리·패배 처리하지 않는다.
- 패널 조회·카메라 이동은 상태·RNG·이벤트 큐·대사 진행을 바꾸지 않는다.

## 완료 기준

- [ ] 확인된 목표가 실제 공개된 시점 이후에만 나타난다.
- [ ] 매핑 없는 전투는 기존 목표 문자열을 보존하고 달성 체크를 추측하지 않는다.
- [ ] 첫 턴·마지막 턴·턴 제한 경계에서 숫자와 ‘현재 턴 포함’ 안내가 일치한다.
- [ ] 목표 대상 교체·퇴각·비공개 전환 뒤 카메라가 다른 인물을 추적하지 않는다.
- [ ] 조회가 승패·이벤트·RNG에 영향을 주지 않으며 기존 판정이 계속 단일 권한을 갖는다.
- [ ] 실제 창의 접기·복원·승리조건 창 왕복을 검증하고 원본 비교 범위를 별도 기록한다.

## 작업 순서

1. 확인된 목표 매핑과 미지원 상태의 표현을 정의한다.
2. 기존 목표·턴·판정 결과를 읽는 presentation projection을 만든다.
3. 패널·접기·공개 대상 이동과 저장 복원을 연결한다.
4. 합성 목표 전환과 실제 창을 검증하며 확인된 전투 범위를 기록한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

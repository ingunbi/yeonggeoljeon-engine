# 06 선택형 전투 이벤트 힌트

- 상태: 부분 구현 · 안정화 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 우선순위: P3
- 개발 단계: M4
- 선행조건: F2 조건 조회, F3 확장 저장, F6 확인 정보 색인
- 기준일: 2026-11-09

## 목적과 현재 구현

조건을 놓치기 쉬운 특수 이벤트를 사용자가 선택한 수준으로 안내한다. 현재 이벤트 처리는 [CampaignVM.swift](../../../Sources/YeonggeoljeonEngine/CampaignVM.swift)의 `queryInvocation`, `predicate`, `dispatch`에 있고, 사용자용 힌트 목록은 없다. 조건 조회를 위해 실제 이벤트를 실행해서는 안 된다.

## 사용 흐름과 화면

1. 전투 메뉴에서 이벤트 힌트를 열고 기본값인 ‘끔’을 가벼운 힌트 또는 조건 자세히로 바꾼다.
2. 현재 전투에서 안내하도록 검토된 항목만 목록으로 표시한다.
3. 가벼운 힌트는 참여 장수나 결말을 숨긴 단서를, 자세한 힌트는 확인된 조건을 보여준다.
4. 확인된 공개 대상만 지도에서 찾을 수 있고, 아직 등장하지 않은 대상의 위치는 표시하지 않는다.
5. 목록을 닫으면 이전 선택 부대와 명령 단계로 돌아온다.

## 구현 범위와 데이터

- 제안 타입 `BattleEventHint`는 전투 ID, 안정적인 힌트 ID, 공개 수준별 문구, 판정 가능한 조건, 근거 참조를 가진다.
- 근거에는 호출자 원본 자료의 식별값과 바이트 위치를 로컬 메타데이터로 보존한다. 원본 대사와 추출 자료는 공개 소스에 넣지 않는다.
- F2에서 변경 없는 조건 투영을 제공한다. 공개용 판정은 ‘충족 / 미충족 / 현재 판단 불가’를 구분한다.
- 실제 사건의 실행과 완료 여부는 VM이 소유한다. 힌트 화면에서 플래그를 바꾸거나 미지원 조건을 우회하지 않는다.
- 전체 이벤트 자동 해독·공략 생성은 이 항목의 범위에 포함하지 않는다.

## 저장과 호환

표시 수준은 사용자 설정으로 저장한다. 회차별 발견·완료 표시는 F3의 회차 확장 데이터에 힌트 ID로 저장하며, 이전 저장에는 발견 기록이 없는 것으로 시작한다. 소스 식별값이 다르면 해당 힌트를 비활성화한다.

## 예외와 취소

- 근거가 없거나 지원되지 않는 조건은 자세한 조건으로 추측해 채우지 않는다.
- 적 비공개 정보와 미래 사건은 스포일러 수준에 맞춰 별도로 차단한다.
- 전투 재시작은 현재 저장 시점의 발견 상태로 돌아간다.
- 설정 변경과 조회만으로 턴, 난수, 이벤트 커서가 진행되지 않는다.

## 완료 기준

- [ ] 기본 설정에서 미발견 이벤트의 존재와 조건을 노출하지 않는다.
- [ ] 세 공개 수준마다 목록·본문·지도 표시가 일관된다.
- [ ] 조건을 조회한 전후 상태와 난수가 동일하다.
- [ ] 힌트의 충족 표시와 합성 이벤트 실행 결과가 일치한다.
- [ ] 자료 불일치와 미지원 조건을 명시하고 정상 전투 진행을 유지한다.

## 작업 순서

근거가 확인된 소수 이벤트의 합성 명세 → 조건 투영 → 공개 수준 필터 → 목록과 지도 연결 → 저장 왕복 검증 순서로 구현한다.

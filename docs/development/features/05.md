# 05. 장수 육성 도우미

- 상태: 구현 · 검증 중 ([현재 구현 범위와 남은 검증](../implementation-status.md))
- 작성일: 2026-11-09
- 우선순위: P2 · 단계: M3
- 선행조건: F1/F2의 결과 분기·경험치 조회 기반. 기존 책략 습득표를 재사용한다.
- 기준: [전체 목록](../../../BACKLOG.md), [공통 구조](../architecture.md), [검증 기준](../verification.md).

## 현행과 차이

- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `showAttackResult`는 실행 뒤 경험치를 보여준다.
- [StrategyLearningGuide.swift](../../../Sources/YeonggeoljeonEngine/StrategyLearningGuide.swift)는 현재 병과의 습득 레벨을 제공한다.
- [OriginalCombat.swift](../../../Sources/YeonggeoljeonEngine/OriginalCombat.swift)의 `experienceGain`, `completeStrategy`, `applyExperience`가 실제 계산을 소유한다.
- 추가 기능은 공격·책략·회복을 실행하기 전에 경험치와 레벨 변화를 조건별로 안내한다.

## 목적과 화면 흐름

1. 공격·책략·회복 대상을 고르면 예측 영역에 경험치 정보를 함께 본다.
2. 명중/실패·격파 여부에 따른 경험치 차이를 펼쳐 확인한다.
3. 레벨업 가능 시 현재와 예상 레벨, 다음 책략까지 남은 레벨을 본다.
4. 책략 이름에서 기존 습득표로 이동하고 돌아오면 선택 상태를 유지한다.
5. 육성 정보는 권고이며 경험치가 적은 행동을 막거나 자동 실행하지 않는다.

## 구현 범위와 진입점

- 신규 타입 제안 `GrowthForecast`는 조건별 경험치, 예상 레벨/잔여 경험치, 다음 습득 항목을 가진다.
- 입력은 현재 source person word, runtime slot, 레벨·경험치와 F1의 실제 효과 분기이다.
- `experienceGain`의 명중 보상·격파 보상과 책략 완료 경험치를 서로 다른 항목으로 유지한다.
- 대상 미선택·날씨 거부·효과 실행 거부는 완료 보상을 얻었다고 표시하지 않는다.
- 여러 대상 책략은 실제 실행·보상 순서를 따르고 임의의 단순 인원수 배수를 사용하지 않는다.
- `applyExperience`를 값 복사에 적용해 레벨 상한·NPC 식별·정수 처리 규칙을 그대로 반영한다.
- 레벨업으로 다음 효과의 계산이 달라지는 경우 해당 실행 순서까지 공통 예측에서 다룬다.
- 다음 습득은 `StrategyLearningGuide.entries`를 재사용하고 현재 병과 기준임을 표기한다.
- 확률이 있는 결과는 ‘명중 시’, ‘격파 시’로 나누며 RNG를 미리 읽어 한 분기를 확정하지 않는다.
- 캠페인 종료 보너스는 현재 행동 보상에 섞지 않고 이 기능의 계산 범위 밖으로 둔다.

## 저장과 예외

- 경험치 예측과 임시 레벨은 저장하지 않는다. 실제 실행 결과만 기존 저장에 반영된다.
- 안내 표시 설정을 추가할 때는 이전 설정의 누락 키를 기본값으로 복원한다.
- 계산 과정에서 사람 데이터, 경험치, 장비, MP, 턴, 로그, RNG를 변경하지 않는다.
- 미지원 후속 효과·스크립트 경계는 경험치 전체를 확정하지 않고 계산 가능한 부분을 구분한다.
- 현재 레벨에서 추가 습득이 없으면 ‘현재 병과의 추가 습득 없음’으로 표시한다.
- 잘못된 표나 원본 이름 누락은 추정 값으로 채우지 않고 읽기 실패로 처리한다.

## 완료 기준

- [ ] 일반 명중·일반 격파·적 지휘관 격파의 보상 차이를 구분한다.
- [ ] 책략 거부·실패·완료·회복의 보상 시점이 실제 규칙과 일치한다.
- [ ] 레벨 상한, NPC 예외, 여러 레벨 상승과 잔여 경험치를 정확히 표시한다.
- [ ] 다음 책략 습득까지 남은 레벨이 현재 병과의 표와 일치한다.
- [ ] 예측 반복 조회와 습득표 왕복 뒤 실제 상태·RNG가 동일하다.
- [ ] 합성 입력의 실행 결과 비교와 실제 화면의 조건 문구 검증을 구분해 기록한다.

## 작업 순서

1. 실제 경험치 생산 지점과 분기별 보상 순서를 정리한다.
2. F1/F2에서 구조화된 성장 예측을 제공한다.
3. 대상 예측 영역과 습득표 연결을 구현한다.
4. 합성 경계 사례와 실제 창 읽기 흐름을 검증한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

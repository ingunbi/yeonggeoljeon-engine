## 현행과 차이

- [OriginalBattle.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattle.swift)의 `attackForecast`는 공격자 한 명과 대상 한 명을 계산한다.
- [OriginalBattleView.swift](../../../Sources/YeonggeoljeonEngine/OriginalBattleView.swift)의 `readyUnits`는 현재 행동 가능한 아군을 찾는다.
- 같은 파일의 `drawForecasts`는 선택한 행동의 수치만 보여준다.
- 추가 기능은 남은 아군의 합법적인 행동 순서를 값 스냅샷에서 비교한다.

## 목적과 화면 흐름

1. 공개된 적을 선택하고 ‘협공 계산’을 연다.
2. 행동 가능한 아군과 가능한 공격·책략 후보를 확인한다.
3. 후보를 순서대로 배치하면 이동 위치, 대상 병력, 반격 위험과 격파 가능성을 비교한다.
4. 선택한 한 행동의 기존 명령창으로 이동할 수 있지만 여러 행동을 자동 실행하지 않는다.
5. 자동 추천은 탐색 범위 안에서 찾은 후보이며 전역 최적해라고 표시하지 않는다.

## 구현 범위와 진입점

- 신규 타입 제안 `CooperativePlan`은 시작 revision, 대상, 순서 있는 행동 후보, 분기별 결과를 가진다.
- 행동 후보는 actor, 가상 이동 경로·도착점, 행동 ID, MP·물품 비용, 피해·반격 조건을 포함한다.
- `readyUnits`와 동일한 수동 행동 자격을 F2로 읽고 이미 행동한 부대는 제외한다.
- 앞 행동의 이동 위치와 점유, 병력·사기·MP·행동 완료를 다음 가상 상태에 반영한다.
- 같은 칸에 둘이 서거나 하나의 소모품을 두 번 사용하는 계획을 허용하지 않는다.
- 피해 계산은 F1/F2를 재사용하며 단순히 최초의 개별 피해를 더하지 않는다.
- 확률 분기는 성공·실패와 반격 여부를 보존한다. ‘항상 격파’, ‘성공 시 격파’, ‘계산 미확정’을 구분한다.
- 현재 RNG를 들여다본 단일 미래 결과로 계획을 확정하지 않는다.
- 퇴각으로 캠페인 스크립트가 실행될 경계 이후는 추정 완료 처리하지 않고 계산을 제한한다.
- 후보 수·탐색 깊이·시간 한도를 두고 중단 시 확인된 후보와 계산 범위를 표시한다.

## 저장과 예외

- 협공 계획은 임시 계산이며 일반·중단 저장에 행동 큐로 저장하지 않는다.
- 실제 상태 변화, 이동 취소, 턴 변경, 불러오기 뒤에는 계획을 폐기한다.
- UI에서 순서를 바꾸어도 세션·RNG·소지품·기록·캠페인 이벤트는 바뀌지 않는다.
- 숨겨진 적이나 미확인 후속 등장 조건을 후보 평가에 공개하지 않는다.
- 한 행동의 명령창으로 넘어갈 때 현재 조건을 재검사하고 자동 실행하지 않는다.
- 합법적인 조합이 없으면 실패 원인을 표시하되 확실하지 않은 가능성을 ‘불가능’으로 단정하지 않는다.

## 완료 기준

- [ ] 이동 순서 때문에 발생하는 자리 충돌과 우회 경로를 후보 검증에서 잡는다.
- [ ] 첫 행동의 병력·사기 변화가 다음 공격 계산에 반영된다.
- [ ] 반격·책략 실패 분기에서 확정 격파와 조건부 격파를 혼동하지 않는다.
- [ ] 스크립트 경계·탐색 한도에서는 보장하지 못한 결과를 명시한다.
- [ ] 순서 편집·취소·시간 제한 종료 후 실제 상태와 RNG가 동일하다.
- [ ] 실제 창에서 선택한 단일 명령 연결과 상태 변경 시 무효화를 확인한다.

## 작업 순서

1. 01·02·17의 예측 결과와 F1 분기 표현을 통합한다.
2. 제한된 두 부대 순서부터 점유·비용·반격 반영을 구현한다.
3. 후보 확장과 탐색 제한, 결과 설명, 단일 명령 연결을 추가한다.
4. 합성 경계 사례를 검증한 뒤 실제 전투 조작에서 계산과 실행이 분리되는지 확인한다.

이 문서는 구현 계획이다. 기능 구현이나 테스트 통과를 의미하지 않는다.

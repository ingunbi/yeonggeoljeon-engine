# 개발 및 안정화 현황

2026년 11월 9일. 42개 설계를 일괄 완료 처리하지 않는다. 아래의 ‘구현·검증 중’은 코드와 합성 검사가 존재한다는 뜻이며, 모든 수용 조건 또는 실제 창 검증을 통과했다는 뜻이 아니다. 사용자 보고에 따라 신규 확장보다 저장 목록·종료 확인창의 배치와 실제 입력 회귀를 우선한다.

## 검증 근거

원본 데이터·대사·이미지가 포함될 수 있는 실행 산출물은 공개 문서에 복사하지 않고 무시된 `build/development-20261109/`에 보관한다.

- `stabilization-build.log`, `stabilization-self-test.log`: 최종 수정 후 통합 빌드와 전체 합성 회귀 검사 통과. 배치 114개, 전투 화면 156개, 아카이브 28개 검사 포함.
- `stabilization-python-tests.log`: 177개 중 154개 통과, 선택 원본 경로가 필요한 23개 생략.
- `stabilization-source-audit.json`: 공개 소스 목록 299개 감사 통과. 공개 배포 또는 원작 실행 동등성의 증거는 아니다.
- `replay-stability-report.json`: 여섯 완료 기록의 백그라운드 재생·취소·본편 상태 보존 검증.
- `stabilization-verification.json`: 화면 검증 범위, 최종 실행 파일 해시, 진행 복원 결과와 한계.
- `practice-play-verification/`: 796개 정상 입력, 완료한 여섯 전투의 재생 상태·난수 일치 및 연습 격리 확인. 엔딩 검증 증거가 아니다.
- `baseline/manifest.json`: 작업 전 저장 파일 해시. 사용자 실제 저장 일곱 파일은 기준 해시와 일치했다.
- `ui-saves/`: 실제 사용자 저장과 분리한 화면 검사 전용 저장 공간.

합성 검사, 자체 엔진의 고정 단계 재생, 실제 macOS 입력은 서로 다른 증거다. 원본 DOS 실행 파일과 런타임 동등성을 비교한 결과로 표현하지 않는다. 이전 공개 엔진 포크는 구현·검증 자료로 사용하지 않는다.

## iPad 분리 작업

사용자 요청에 따라 공용 실행 모델을 유지하고 iPad용 SwiftUI/UIKit 화면을 추가했다. 맥 AppKit 창과 별도 앱이며 저장 공간도 분리한다. 범위와 빌드·실기기 검증은 [iPad 독립 실행 문서](../ipad-testing.md)에서 관리한다. iPad 빌드 성공을 위 42개 과제 또는 엔딩 검증의 완료로 처리하지 않는다. 별도 맥 QA 앱은 사용자 지적 이후 자동 실행하지 않는다.

# iPad 독립 실행

2026-11-09. 기존 Swift 실행기와 전투·저장 모델을 공유하고, iPad 화면과 입력은 SwiftUI/UIKit으로 구성한다. 맥 화면을 전송하지 않으며 게임 자료는 앱 안에 포함한다. 이전 공개 엔진 포크는 사용하지 않는다.

## 구현 범위

- 가로·세로 화면, 지도 드래그·확대, 최소 44pt 전장 칸, 공개 장수 선택
- 원본 대사·선택·출전 편성·상점·도시 입장과 목적지 이동
- 아군 선택·이동·취소·공격·책략·도구·대기·턴 종료
- 책략 습득 레벨·효과·사거리·범위와 현재 전투 결과 기록
- 일반 슬롯, 자동 저장, 전투 시작, 별도 1회 중단 저장과 파일 가져오기
- 비활성 시 진행 정지, 복귀 시 경과 시간 몰아서 처리하지 않음

초기 iPad 화면은 전장 위에 결과를 반영한다. 확대 교전·일기토의 전용 연출과 맥의 모든 플레이 보조 화면을 이식한 상태는 아니다. 화면 생략이 원본 실행 옵션이나 난수 소비를 바꾸면 안 된다. 미지원 명령은 명시적 오류로 멈춘다.

## 화면 구성과 터치 (2026-11-13 개편)

- 맵 화면(마을·궁전·세계지도)은 지도 창만 잘라 크게 보여준다. 인물을 누르면 대화가 시작되고, 길·문을 누르면 그 칸으로 걷는다. 세계지도는 도시를 눌러 행군하고, 끌어서 한 칸씩 스크롤한다.
- 대사는 화면 아래 카드(초상·화자·본문)로 보이며 화면 어디를 눌러도 다음으로 넘어간다.
- 하단은 아이콘이 달린 명령 막대(이동·공격·책략·도구·대기·취소·턴 종료)다. 예/아니요 같은 짧은 질문은 나란한 버튼, 슬롯·메뉴 같은 긴 선택은 목록 행으로 보인다. 메뉴는 내용 높이에 맞는 시트다.
- 대사 카드에 "자동"(읽을 시간을 둔 뒤 자동으로 넘김)과 "건너뛰기"(선택지·편성 같은 결정이 나올 때까지 빠르게 넘김) 버튼이 있고, 위쪽 "1×/2×/4×" 버튼은 진행 속도를 바꾼다. 셋 모두 입력이 닫히는 시점·진행 속도만 바꾸며 게임 규칙·난수는 바꾸지 않는다.
- 전투에서 부대를 선택하면(적군 포함) 왼쪽 위에 정보 카드가 뜬다: 초상·병과·레벨, 병력·사기·MP 게이지, 지형·혼란 상태, "상세"(책략 습득표). 직접 조작할 수 없는 부대(아군 AI·행동 완료)는 명령 버튼이 꺼진다.
- 전투 행동은 맵 위에서 재생된다: 걷기(방향·걸음 그림), 화살·돌 발사, 타격 효과, 피해·회복 숫자, 단계 알림(레벨 업 등은 눌러서 계속). 확대 전투 장면과 일기토 연출은 그리지 않고 결과 숫자로 줄여 보여준다. 위쪽 1×/2×/4×가 재생 속도도 바꾼다.
- 메뉴에 "설정"(배경음악·효과음·소리 크기·대사 자동 넘김 속도·진행 속도)과 "총퇴각"(전투 시작 시점으로 되돌림, 원본 확인 문구 사용)이 있다.
- 타이틀은 그림 전체를 보이고 아래에 세 버튼만 둔다. 엔진의 영어 오류 접두어는 화면에 내보내지 않는다.
- 시뮬레이터(iPad Air 11-inch M4)에서 확인: 정보 카드, 설정·퇴각 메뉴, 적·아군 차례의 피해 숫자 재생, 새 게임 도입 대사 건너뛰기·2× 속도, 타이틀·불러오기·전투 시작 저장 불러오기·대사 넘기기·부대 선택·이동·대기·턴 종료(적 차례를 거쳐 2턴)·시트 크기. 세로 화면 기준이며 가로 화면과 실기기 터치 감각은 아직 확인하지 않았다.

## 빌드

설치된 Xcode와 시스템 Python을 사용한다. `PREPARED_DATA`는 사용자가 선택한 원본에서 자체 도구로 추출한 GameData 폴더여야 한다. 원본 DOS 실행 파일은 실행하지 않는다.

```sh
/usr/bin/python3 tools/build_ipad.py --data "$PREPARED_DATA" --generate-only
/usr/bin/python3 tools/build_ipad.py --data build/ipad/GameData \
  --team "$DEVELOPMENT_TEAM" --device "$IPAD_DEVICE"
```

전장 타일 변경을 표시하려면 `tools/prepare_battles.py`로 같은 원본에서 생성한 `battle-tile-atlases.json`과 해당 atlas PNG도 GameData에 포함한다. 모든 원본 자료·추출물·생성 Xcode 프로젝트·서명 앱·장치 식별 보고서는 무시된 `build/ipad/` 아래에 둔다. `iOS/SharedSources.json`은 배포 대상 공용 소스의 명시적 목록이며, 빌드 입력 해시는 `ipad-build-inputs.json`에 남긴다.

서명을 생략한 빌드 또는 대상 기기가 서명 프로파일에 포함되지 않은 빌드는 해당 기기에 설치 가능한 앱이라는 뜻이 아니다. `--sdk iphonesimulator`는 시뮬레이터용이다. 실기기에는 Xcode에 설정된 개발 팀과 기기 등록, 개발자 모드가 필요하다. `--device`를 지정하면 Xcode가 해당 기기를 개발 프로파일에 등록한다. [Apple의 개발자 모드 안내](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)를 따른다.

```sh
xcrun devicectl device install app --device "$IPAD_DEVICE" \
  build/ipad/DerivedData/Build/Products/Debug-iphoneos/Yeonggeoljeon.app
xcrun devicectl device process launch --device "$IPAD_DEVICE" \
  org.yeonggeoljeon.engine.ipad
```

## 저장

저장은 iPad 앱의 `Documents/YeonggeoljeonSaves`에 보관한다. 맥의 사용자 저장을 직접 읽거나 덮어쓰지 않는다. 파일 공유를 지원하므로 Finder 또는 파일 앱에서 복사할 수 있다. 화면 상단 폴더 버튼은 자체 엔진의 일반 JSON 저장 파일을 가져온다. 원본과 다른 자료로 작성된 저장은 검증 실패 시 현재 진행을 유지한다.

중단 저장은 일반 슬롯과 별도 한 칸이며 안전한 실행 경계에서 작성한 뒤 타이틀로 돌아간다. 이어하기의 상태 복원에 성공했을 때만 소모한다. 자동 저장과 전투 시작 저장은 반복해서 불러올 수 있다.

## 검증 구분

- iPhoneOS SDK에서 공용 코어와 터치 화면 빌드·개발 서명 통과.
- 타일 atlas와 기존 정적 지도 58개, 136,952개 타일의 RGBA 일치 확인. 원본 DOS 프레임버퍼와의 비교는 아니다.
- 합성 입력으로 확대·스크롤 역좌표, 지도 경계와 비정상 좌표 거부, 최소 터치 크기 확인.
- 실제 터치 컨트롤러를 화면 없이 구동한 46개 검사: 사수관 36개 정상 입력의 매 단계 상태·난수가 별도 재생기와 일치했다. 전투 시작 저장, 중단 저장·소모·동일 복원, 비활성 30틱 불변을 확인했다. 연출 생성 여부를 달리한 재생도 최종 상태·난수가 같았다.
- 별도의 변경 상태를 가진 로컬 컨트롤러 fixture에서 52개 검사 통과: 시전자 중심 책략, MP·물품 소모, 확정 전 재검사, 도구 전달, 이동 취소. 이 검사는 정상 플레이 경로와 구분한다.
- 연결된 iPad mini 6세대(iPadOS 27.0.1)에 개발자 모드를 켜고 기기를 포함한 서명으로 앱을 설치했다. 사용자의 개발자 신뢰 확인 후 실행 성공. Device Hub의 실제 기기 화면에서 새 게임·대사 전환, 도입 중단 저장·타이틀 복귀, 맥 저장 사본 불러오기·사수관 첫 턴 지도·부대 선택·이동·취소를 확인했다. 전투 중단 저장 후 타이틀→이어하기→동일 첫 턴 화면 복원을 확인했고, 실기기 파일 목록에서 `suspend.json`만 소모되고 일반/전투 시작 저장은 유지됨을 확인했다.
- 자체 엔진의 첫 여덟 전투 정상 입력 검증은 iPad 화면에서 여덟 전투를 플레이했다는 뜻이 아니다. 엔딩까지 정상 완주 역시 미확인이다.

실기기 검증 시 새 게임의 전투 진입, 빈 대사 없음, 이동·취소·공격·책략·도구, 일반 저장·중단 저장, 비활성·복귀, 회전·확대를 각각 확인한다. 기존 사용자 진행을 검사 파일로 덮어쓰지 않는다.

현재 실기기 확인은 위에 기록한 화면·입력 범위다. 공격·책략·도구·전달은 컨트롤러 검사로 확인했으며 실제 기기의 전투 실행, 회전·핀치, 장시간 성능·배터리·음향 확인은 남아 있다. 테스트 기기는 사수관 첫 턴으로 두었고, 불러오기 5번 슬롯에 맥 전투 시작 저장 사본이 있다. 개인 개발 서명은 기간이 제한되므로 만료 시 같은 앱 ID로 다시 서명·설치한다.

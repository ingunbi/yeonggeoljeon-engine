# Yeonggeoljeon Engine · 영걸전 자체 엔진

한국어 DOS/V판 **삼국지 영걸전**의 자료와 실행 동작을 분석하여 만드는 새
네이티브 엔진입니다. 공개 엔진을 수정했던 이전 시험 앱과 분리된 프로젝트이며,
원작 자료를 직접 읽는 타이틀·첫 궁전 장면부터 구현했습니다.

현재 단계는 **0.1.0 초기 연구용 구현**입니다. 전체 캠페인을 플레이하는
완성 엔진은 아닙니다.

## 현재 구현과 검증

- 자체 LS11·NPK·planar 해독기로 원작 그림을 읽습니다. 첫 궁전 지도, 소품 12개,
  인물 그림 29묶음과 원본 인물 식별자 384개의 연결을 내보냅니다.
- 원작 첫 궁전 레코드를 직접 해석하여 명령 40개를 실행합니다. 인물 10명의
  등장, 동시 이동, 퇴장, 원문 대사 7개를 포함합니다.
- 타이틀·대사 확인 입력, 원작 격자 경로 찾기와 명령 실행 상태를 새로 작성했습니다.
  원작 코드에서 정적으로 도출한 기본 이동 간격을 사용하지만 DOS의 정확한
  타이머·보행 그림 전환 주기와의 동등성은 아직 검증하지 않았습니다.
- 2026-10-25 Apple Silicon Mac에서 데이터 테스트 23개와 네이티브 자체 진단
  22항목을 통과했습니다. 실제 원작 자료 검사와 합성 입력 검사를 구분해 실행했습니다.
- 설치 앱에서 첫 장면을 원본 FF 경계까지 재생하여 실제 렌더 PNG 5장을
  생성했습니다. 별도로 macOS 창에서 Return 입력에 의한 타이틀 전환·대사·이동도
  직접 확인했습니다. 원작 실행 화면과의 전체 동등성 검증은 아닙니다.

해독하지 않은 명령·잘못된 경로는 완료로 가장하지 않고 결과와 실패 이유를
기록합니다. 기본 진단은 사용자 진행 상태를 읽거나 저장하지 않습니다.

원작 초상화 압축, 원작 글꼴·UI, 소리, 전체 오프닝, 마을 자유 이동, 전투·AI,
전체 캠페인과 진행 저장은 아직 구현하지 않았습니다. 궁전 팔레트 슬롯 선택은
이전 연구에 따른 추론이며 해당 선택 명령을 다시 확인해야 합니다. 소품 가림은
전체 이미지 깊이 정렬로 구현했고 원작의 셀 단위 부분 가림은 미복원입니다.

## 구성

- `tools/`: 원작 리소스·시나리오 해독과 macOS 앱 제작. Python 표준 라이브러리 사용.
- `Sources/YeonggeoljeonEngine/`: 새 장면 실행기·화면·입력. Swift/AppKit/CoreGraphics 사용.
- `Tests/`: 원작 파일을 포함하지 않는 합성 자료 테스트.
- `research/`: 자료 식별, 분석 근거, 구현 계약. 로컬 보고서는 `research/local/`.

외부 게임 엔진과 공개 대체 그림 묶음은 사용하지 않습니다. 원작 게임 파일,
추출 그림·대사, 빌드한 앱은 이 소스 저장소에 포함하지 않습니다. 사용자가
보유한 원작 자료를 지정하면 자신의 컴퓨터에서 실행 자료를 생성합니다.

## macOS 빌드

Apple Silicon Mac, 설치된 Xcode Command Line Tools, Python 3.11 이상이 필요합니다.
빌드 도구는 전역 패키지나 다른 실행 환경을 설치하지 않습니다.

```sh
python3 tools/build.py --game /path/to/original/GAME --verify
```

`--game`에는 `GAME/` 폴더가 들어 있는 원본 ZIP도 지정할 수 있습니다.
해독 대상 파일은 읽기만 하며, ZIP을 지정하면 임시 빌드 폴더로 추출합니다.

제공된 판본의 `OPGRP.R3` 배경 영역은 손상되어 있습니다. 정상 자료를 별도로
보유한 경우에만 `--title-opgrp /path/to/intact/OPGRP.R3`를 지정할 수 있습니다.
도구는 다른 원작 파일을 자동으로 다운로드하지 않습니다. 복구 자료의 출처는
사용자의 로컬 해독 보고서에 기록합니다.

결과 앱은 `build/Yeonggeoljeon Engine.app`입니다. `--install`을 추가하면
`~/Applications/Yeonggeoljeon Engine.app`에 별도로 설치합니다. 실행 후 Return·Space·
클릭으로 대사를 진행하고 Esc로 종료합니다. 기존 시험 앱과 저장 파일은 사용하지
않습니다. 첫 궁전 레코드가 끝나면 현재 복원 범위를 알리는 화면에서 멈춥니다.

```sh
python3 -m unittest discover -s Tests -v
swift run yeonggeoljeon-engine --self-test
python3 tools/audit_source.py --output build/source-audit.json
python3 tools/source_release.py
```

기본 Python 검사는 원작 파일이 없어도 실행됩니다. 실제 자료 검사 두 개는
`ORIGINAL_GAME_DIR`, 정상 타이틀 자료 검사는 추가로 `TITLE_OPGRP_FILE`을 지정해야
실행됩니다. 선택하지 않은 실물 검사는 통과로 계산하지 않고 건너뜁니다.

`tools/source_release.py`는 공개 후보 소스 목록을 검사하고 파일별 SHA-256을
ZIP에서 다시 읽어 확인합니다. 결과는 `build/yeonggeoljeon-engine-source.zip`이며,
원작 콘텐츠와 로컬 앱은 포함하지 않습니다. 이 명령은 인터넷에 게시하지 않습니다.

## 개발 원칙

원작 자료와 정적 분석이 뒷받침하는 부분부터 구현합니다. 해석하지 못한 명령은
명시적으로 멈추며 임의의 장면으로 대신하지 않습니다. 새로운 엔진의 실행·렌더
검증과 원작 실행 결과의 대조는 별도로 기록합니다.

이전 공개 엔진 소스를 본 이력이 있으므로 법적으로 격리된 클린룸 개발이라고
주장하지 않습니다. 새 구현의 자료와 출처는 [research/README.md](research/README.md)에
정리합니다. 참여 방법은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참조하세요.

새 엔진 코드의 공개 라이선스는 [GPL-3.0-only](LICENSE)입니다.
원작 게임 콘텐츠의 권리는 엔진 코드의 라이선스에 포함되지 않습니다.
